# 사진 메시지 프롬프트 (64장)

채팅 속 `photo` 줄(사진 카드)마다 한 장씩 그리는 프롬프트다. 공통 규칙·만드는 순서·수정 문장은 [../IMAGE_PROMPTS.md](../IMAGE_PROMPTS.md) 를 따른다. 크기는 모두 정사각 1024×1024, 저장 위치는 `assets/photos/`.

## 파일 이름 규칙

- 이름은 **사진이 나오는 이벤트의 id** 다: `assets/photos/<이벤트 id>.png`.
- 한 이벤트에 사진이 여러 장이면 **줄 순서**대로 두 번째부터 `_2`, `_3`, `_4` 를 붙인다.
  줄 순서 = 이벤트 `lines` 를 위에서부터, 그다음 `choices` 를 0번부터, 한 선택지 안에서는 `reply` → `failReply` → `critReply` 순.
  예) `mo_seoyeon_photo_night.png`(본문 사진) · `_2`(선택 1 reply) · `_3`(선택 1 failReply) · `_4`(선택 1 critReply).
- 대사를 고쳐 사진 줄을 넣거나 빼면 뒤 번호가 밀린다. 그때는 이 문서도 같이 고친다.

## 이 문서에서 지킨 것

- 사진은 **보낸 사람이 휴대폰으로 찍은 한 장**이다. 셀카·음식·창밖·영수증 그림처럼 그 사람의 시선과 손길이 보이게 썼다.
- **보낸 사람이 `나(플레이어)`인 사진이 29장**이다. 주인공은 얼굴이 절대 나오지 않는다(손끝·발끝·뒷모습·그림자까지만).
- 캐릭터가 화면에 나오는 사진만 초상화를 첨부한다(6장: 하늘 2, 예은 2, 건우 1, 도윤 1). 나머지는 **첨부 없음**이고, 소매·손목·소품으로 누구 사진인지 느껴지게 했다.
- 캡션이 똑같은 사진(같은 사진을 다시 보내는 경우 포함) 5쌍은 한 번만 그리고 **파일을 복사**해도 된다. 해당 항목에 적어 두었다.
