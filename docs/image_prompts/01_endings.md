# 엔딩 일러스트 프롬프트 (60장)

엔딩 화면 상단과 앨범 엔딩 카드에 들어가는 "엔딩 CG" 프롬프트다. `assets/story/endings.json` 의 엔딩 60개를 하나씩 다룬다.
공통 규칙·만드는 순서·수정 문장은 [../IMAGE_PROMPTS.md](../IMAGE_PROMPTS.md) 를 따른다.

- **저장 위치:** `assets/endings/<엔딩 id>.png` (예: `assets/endings/seoyeon_happy.png`). 파일 이름이 id 와 다르면 앱에 안 뜬다.
- **크기:** 모두 세로 2:3, 1024×1536. 넣기 전에 `sips -Z 1350 assets/endings/*.png` 로 줄인다.
- **첨부:** 캐릭터가 나오는 장은 적힌 초상화(`assets/portraits/<id>.jpg`)를 먼저 올리고 블록을 통째로 붙여 넣는다.
  "첨부 없음" 장은 주인공만 나오는 장면이다(1인칭 손 또는 뒷모습).
- **주인공 얼굴은 어느 장에도 나오지 않는다.** 주인공의 손·소매는 성별이 드러나지 않게 무난한 옷으로 적었다.
- **추천 순서: 캐릭터별 해피(`*_happy`) 12장을 먼저 만든다.** 수집 동기가 가장 큰 그림이다. 그다음 천생연분 12장 → 굿 12장 → 배드 12장 → 솔로·히든·공용 12장.
- 캐릭터 순서는 초상화 문서와 같다. 여성 캐릭터 쪽(서연·다은·지우·소희·예은·유나) → 남성 캐릭터 쪽(정우·하늘·승현·민재·건우·도윤).
