## 2. 새로 쓴 장면 네 편

날짜는 **D+25 와 D+27** 이다. 둘 다 메인이 비어 있던 날이고(`m09`=23, `m10`=26, `m11`=29),
엔진의 "같은 날 같은 쪽에 메인 하나" 규칙(`story_repository.dart:393-404`)에 걸리지 않는다.
쪽별(f/m)로 하나씩이라 D+25 에 둘, D+27 에 둘이 들어간다.

`refused_mom` 과 `lied_to_mom` 을 **한 이벤트로 합치지 않고 날짜를 갈랐다.** 트리거의 `flags` 는 AND 라
"둘 중 하나"를 한 줄로 못 쓴다 — 그런데 거짓말쟁이와 거절자는 애초에 다른 장면을 받아야 하므로
이 제약이 오히려 맞았다.

### 2.1 `m10_refused` (D+25, 여성향) — "정정하고 싶어서요"

`m10` 의 첫 줄은 태현이다("야 코스는 짰냐"). 이 문의 첫 줄은 **지우 본인**이고, 용건이 데이트가 아니다.
`m03` 의 클리프행어 — *"엄마가 벌써 아주머니에게 답장을 보냈다"* — 가 이 장면의 전제다.
내 번호는 이미 넘어가 있었고, 취소 책임이 **지우 쪽으로 정리돼 있었다.**

```
(지문) 저장 안 된 번호. 프로필에 사진이 없다.
지우:  안녕하세요. 이 번호 맞나요. 확인부터 할게요
나:    …네 맞는데요
지우:  지우예요. 어머니들끼리 잡으셨던 그 자리요
지우:  취소된 건 아시죠
       [읽씹 대기 15초]
지우:  그게 제가 취소한 걸로 정리돼 있더라고요
지우:  저희 어머니한테도, 그쪽 어머니한테도요
지우:  정정하고 싶어서 연락드렸어요. 그게 다예요
```

변호사가 **기록을 바로잡으러** 온 것이다. 소개팅이 아니라 정정 요청이고, 그래서 첫 선택지도 다르다:
사과 / 되받아침 / **"엄마들이 정한 자리잖아요. 왜 우리가 사과해요"**(대화 30 필요) / T·F 분기.
세 번째를 고르면 지우가 처음으로 `ㅋ` 를 하나 붙인다.

클리프행어: `지우: "정정은 제가 할게요. 대신 한 번은 직접 뵙고 싶은데요."`

### 2.2 `m10_refused_m` (D+25, 남성향) — "한 번은 말해야 할 것 같아서요"

승현은 ISTJ 수의사다. `seunghyun_r00` 에서는 *허락을 구한다*("부담되시면 거절하셔도 됩니다").
이 문에서는 **이미 거절당한 뒤**라 구할 허락이 없다. 그래서 그냥 사실 하나를 놓고 간다.

```
(지문) 저장 안 된 번호. 프로필 사진은 강아지 뒤통수다.
승현:  안녕하세요. 승현입니다. 어머님께 번호 받았습니다
승현:  자리가 없어졌다고 들었어요. 그건 괜찮습니다
       [읽씹 대기 12초]
승현:  그래도 한 번은 말해야 할 것 같아서요
승현:  저는 나가려고 했었어요
승현:  이 말 안 하면 계속 생각날 것 같아서요. 그게 다예요
```

선택지 "왜 지금 말해요?" 에 대한 답이 그의 핵심이다 — *"저는 미루면 그냥 안 하는 사람이에요. 그게 싫어서요."*
"그럼 지금이라도 나갈게요. 날짜 주세요"를 고르면 `seunghyun_r01` 의 습관(후보 세 개)이 그대로 돌아온다.
크리티컬 대사: *"좋아요. 확실히. 저 지금 병원에서 혼자 웃었어요."*

클리프행어: `승현이 날짜 후보 세 개를 보냈다. 이번엔 어머니 얘기가 없다.`

### 2.3 `m10_lied` (D+27, 여성향) — "사실관계가 안 맞아서요"

**거짓말쟁이는 거절자와 다른 장면을 받는다.** 날짜도 다르다 — D+27 은 **소개팅이 있었어야 할 날의 다음 날**이다.

```
(지문) 토요일이 그냥 지나갔다. 아무 일도 없었다.
(지문) 일요일 오후, 저장 안 된 번호에서 톡이 왔다.
지우:  안녕하세요. 지우예요. 번호는 어머니들 통해서 받았어요
지우:  만나는 분이 계시다고 들었어요. 축하드려요
       [읽씹 대기 12초]
지우:  그런데 사진 한 장만 보여 달라셨을 때 못 보여주셨다면서요
지우:  거짓말이라는 게 아니라, 사실관계가 안 맞아서요. 직업병이에요
지우:  솔직히 말하면 저도 안 나가고 싶었거든요. 핑계가 부러웠어요
```

`m03` 의 "사진 보내봐. 지금 / 보낼 사진이 없다"를 **2주 뒤에 회수한다.**
지우는 고발하지 않는다. 부러워한다 — 그래서 선택지가 거절 쪽과 완전히 다르다:
실토 / 끝까지 우기기(흑역사 `없는 애인 끝까지 우기기`) / **"핑계 필요하시면 저 쓰셔도 돼요"**(공범 제안) / T·F.

공범 제안의 답: *"지금 저한테 공범 하자고 하신 거예요" / "변호사한테요?" / "…좋아요. 한 번은 뵙죠."*
끝까지 우겨도 만남은 성사된다 — *"근데 취소된 자리 때문에 한 번은 뵈어야 해요. 어머니들이 안 끝내 주셔서요."*

### 2.4 `m10_lied_m` (D+27, 남성향) — "저는 그 핑계를 못 대요"

지우가 **부러워한다면**, 승현은 **자기 얘기를 해서 문을 열어 둔다.**

```
승현:  만나는 분이 있다고 들었어요. 그럼 저는 여기서 끝내는 게 맞습니다
       [읽씹 대기 12초]
승현:  그런데 저희 어머니가 그 얘기를 하시면서 웃으시더라고요
승현:  저희 엄마는 거짓말할 때 웃어요. 10년 봤어요
승현:  아니면 아니라고만 해 주세요. 그럼 저는 다시 시작할 수 있어요
```

T 선택지 "어머니가 웃었다는 게 근거예요?" → *"네. 10년치 표본이에요. 진료도 그렇게 봐요. 주인 얼굴부터 봅니다."*
실토 크리티컬 → *"그럼 처음부터 다시 할게요. 안녕하세요, 승현입니다."*
클리프행어도 같은 몸짓이다: `승현: "다시 인사드릴게요. 승현입니다."`

## 3. 플래그 모양 — 그리고 왜 이 모양이어야 했나

### 3.1 결정

| 플래그 | 뜻 | 세우는 곳 | 읽는 곳 |
|---|---|---|---|
| `jiwoo_intro` · `seunghyun_intro` | **소개팅을 수락했다** | `m03`·`m03_m` 의 "나간다" | `jiwoo_r01`, `seunghyun_r00`·`r01` (소개팅 전 문자 장면) |
| `jiwoo_met` · `seunghyun_met` | **어느 문으로든 선이 닿았다**(중립) | 수락(`m03`·`m03_m`) + 두 번째 문 4편 | 모먼트 8종, `jiwoo_mbti_talk`·`seunghyun_mbti_talk` |
| `jiwoo_no_setup` · `seunghyun_no_setup` | **소개팅 없이 만났다** | 두 번째 문 4편 | `signals.json` 관찰문 |
| `lied_caught` | **거짓말이 상대 귀에 들어갔다** | `m10_lied`·`m10_lied_m` | `signals.json` 관찰문 |
| `jiwoo_dated` · `seunghyun_dated` | 다음 약속까지 갔다 | `m11`·`m11_m` | `signals.json` 관찰문 |

`seunghyun_met` 은 **원래 있던 이름을 재사용한 것**이다 — `seunghyun_r02` 가 세우고
`seunghyun_mbti_talk` 가 읽고 있었다. 뜻(만났다)이 그대로라 새 이름을 만들지 않았다.
지우 쪽은 `jiwoo_texted`(소개팅 전 문자) 를 읽던 `jiwoo_mbti_talk` 를 `jiwoo_met` 로 옮겨 대칭을 맞췄다.

### 3.2 진짜 열쇠는 플래그가 아니라 **D+29 를 무조건으로 만든 것**이었다

`m11`·`m11_m`·`m12`·`m12_m` 의 `trigger.flags` 를 **없앴다.** 이제 D+29·D+32 메인은 쪽만 보고 무조건 나온다.
세 문 전부 D+29 보다 앞(D+25·26·27)에 있으므로, **"만난 적이 있다"는 날짜가 보장한다.**

그래서 루트 `jiwoo_r03`~`r15` · `seunghyun_r03`~`r15` 26개의 `*_dated` 게이트를 **전부 뺐다.**
이 26개의 `day` 하한은 전부 **30 이상**이라, 합류점(D+29)이 무조건인 이상 날짜만으로 순서가 지켜진다.

이게 `route_order_test` 의 정적 검사가 원래 통과하던 방식이기도 하다.
`mustPrecede()` 는 "`trigger.flags` 가 비어 있고 `day` 가 더 이른 main 이벤트"를 자동으로 선행에 넣는다
(`test/route_order_test.dart:933-944`). 09 에서 `m11` 에 플래그를 붙이는 순간 `m11` 이 그 집합에서 빠졌고,
그걸 메우려고 `*_dated` 를 26곳에 심은 것이었다. **플래그를 빼니 두 검사가 동시에 통과한다.**

> `jiwoo_r03` 의 `flags` 를 비우면 "소개팅을 안 해도 지우 루트가 돈다"는 07 (c)#6 이 돌아오는 것 아닌가?
> **아니다.** 그때는 *만난 적 없이* 루트가 돌았다. 지금은 세 문 중 하나가 **반드시** D+25~27 에 실행되고
> D+29 에 합류점이 있다. 즉 "루트가 게이트 없이 돈다"가 아니라 **"게이트가 이제 날짜에 들어 있다"** 이다.

### 3.3 안 한 것

- **`m11` 에 문별 대사 분기를 못 넣었다.** `Line` 은 MBTI·궁합만 걸 수 있고 플래그 조건이 없다
  (`models.dart:474-541`). 그래서 첫 지문 두 줄을 **문 중립**으로 다시 썼다:
  `소개팅은 두 시간 만에 끝났다` → **`지우를 만나고 오는 길이다. 두 시간.`**
  제목도 `애프터 신청` → **`다음 약속`**(애프터는 소개팅 어휘다).
- **`jiwoo_intro`·`seunghyun_intro` 를 안 지웠다.** 지금 세이브와 `route_order_test` 의
  `jiwoo_r01 ← m03` · `seunghyun_r00/r01 ← m03_m` 정적 검사가 이 이름에 걸려 있다.
