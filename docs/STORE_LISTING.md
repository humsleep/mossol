# App Store 등록 문구 — 모쏠 탈출기 (한국어)

App Store Connect → 앱 → 버전 정보(한국어)에 그대로 붙여 넣는 문서다. 글자 수는 공백·문장부호 포함이며,
각 칸 옆에 실제로 센 값을 적었다(2026-09-22). 이름·부제·키워드 규칙은 `docs/RELEASE_CHECKLIST.md` §0을 따른다.

- 앱 이름(30자): `모쏠 탈출기 : 100일 연애 시뮬레이션` — 그대로.
- 문구 원칙: 게임에 실제로 있는 것만 쓴다. 다른 앱·메신저·브랜드 이름을 쓰지 않는다("카톡 같은" 금지 → "메신저", "톡").
  무료이며 광고가 있다는 것을 설명에 분명히 쓴다.
- 확인한 사실: 남녀 캐릭터 각 6명(총 12명, 쪽마다 1명은 숨겨진 캐릭터), 엔딩 60개(`assets/story/endings.json`),
  미니게임 12종, 전화·사진 카드·하루 정산·흑역사/엔딩 앨범, 성별 선택(선택 안 함 가능), MBTI 선택(건너뛰기 가능),
  로그인 없음·기기에만 저장, 하트(행동력)는 시간으로 회복되고 보상형 광고로 즉시 1개 받기, 전면 광고 있음, 인앱 결제 없음.

## 1. 부제 (30자 이내)

| | 문구 | 글자 수 |
|---|---|---|
| 현재 (추천) | `톡 한 줄로 썸부터 고백까지` | 15 |
| 대안 1 | `읽씹부터 고백까지, 설레는 연애톡` | 19 |
| 대안 2 | `답장 하나에 설레는 메신저 연애` | 17 |

- 이름에 "100일 연애 시뮬레이션"이 들어가므로 부제는 **메신저(톡) + 목표**만 말한다(2026-09-22 이름 변경에 맞춰 바꿈). 대안 1은 "읽씹" 공감 포인트, 대안 2는 감정 쪽이다.
- **부제를 바꾸면 키워드도 바꾼다.** 부제에 들어간 단어는 키워드 칸에서 뺀다(§4 아래 교체표).

## 3. 설명 (4000자 이내)

첫 3줄이 "더 보기" 앞에 보인다. 첫 줄은 공감, 둘째 줄은 무슨 게임인지, 셋째 줄은 선택의 긴장감.

```
답장 하나에 설레고, 읽씹 하나에 밤새 뒤척여 본 적 있나요?
연애 경험 0인 20대 중반 모쏠이, 100일 동안 메신저로 썸을 타고 고백까지 가는 연애 시뮬레이션이에요.
오늘 보낸 한 줄이 내일의 관계를 바꿔요.

■ 메신저 속 진짜 같은 썸
• 휴대폰 메신저처럼 오가는 대화에서 내 답장을 직접 골라요
• 답장이 늦으면 서운해하고, 다른 사람 얘기를 하면 질투해요
• 갑자기 걸려 오는 전화, 말없이 보내오는 사진 한 장
• 하루가 끝나면 "가까워졌다", "조금 멀어졌다"로 관계가 정리돼요
• 다음 날이 궁금해지는 한 줄 예고로 하루가 끝나요

■ 누구와 설렐지 내가 정해요
• 남성 캐릭터 6명, 여성 캐릭터 6명, 총 12명
• 성별을 고르면 그에 맞는 사람들을 먼저 만나요. 고르지 않고 양쪽을 다 둘러볼 수도 있어요
• 동아리 선배, 소개팅 상대, 초등학교 동창까지, 사람마다 말투도 사연도 달라요
• 아직 소개되지 않은 숨은 캐릭터도 있어요

■ MBTI 궁합
• 내 MBTI를 고르면 캐릭터별 궁합이 하트로 보여요
• 몇몇 장면과 대사도 내 성격 유형에 따라 달라져요
• 잘 몰라도 괜찮아요. 건너뛰고 나중에 설정에서 바꿀 수 있어요

■ 100일, 엔딩 60개
• 고백에 성공하는 해피 엔딩부터 씁쓸한 엔딩, 숨겨진 엔딩까지 60개
• 어떤 답장을 보냈는지에 따라 전혀 다른 결말로 이어져요
• 실패한 순간도 흑역사 앨범에 모여 수집 요소가 돼요

■ 짧게 즐기는 미니게임 12종
• 답장 타이밍 맞추기, 프로필 고르기, 옷장 코디, 코스 짜기, 5초 안에 메시지 삭제하기 등
• 결과에 따라 매력, 화술, 눈치 같은 능력치와 호감도가 달라져요

■ 부담 없이
• 회원가입, 로그인 없이 바로 시작해요
• 진행 상황은 이 기기에만 저장돼요
• 다크 모드를 지원해요

■ 안내
• 무료로 즐길 수 있으며, 게임 중 광고가 표시돼요
• 행동에 쓰는 하트는 시간이 지나면 다시 채워지고, 원하면 광고를 보고 바로 받을 수 있어요
• 게임 속 인물과 사건은 모두 가상이에요
```
(998자 — 고치면 §8의 명령으로 다시 센다)

- "MBTI"는 The Myers-Briggs Company의 상표다. 설명에서 게임 기능을 가리키는 정도는 흔히 쓰이지만, 반려되면
  "16가지 성격 유형"으로 바꾼다(프로모션 텍스트 포함). **키워드 칸에는 넣지 않는다.**

## 4. 키워드 (100자 이내, 쉼표로 구분, 쉼표 뒤 공백 없음)

현재 이름·부제 기준. 이름·부제에 있는 단어(모쏠, 탈출기, 100일, 연애, 시뮬레이션, 톡, 썸, 고백)는 넣지 않았다.
상표(메신저 앱 이름, SNS 이름, MBTI, 모태솔로 등)도 넣지 않았다.

```
게임,미연시,메신저,채팅,대화,문자,읽씹,질투,밀당,소개팅,짝사랑,썸남,썸녀,남친,여친,로맨스,여성향,스토리,선택지,멀티엔딩,비주얼노벨,궁합,성격유형,두근두근,캐릭터,답장,설렘
```
(98자)

**부제를 바꿨을 때 교체**
- 대안 1(`읽씹부터 고백까지, 설레는 연애톡`): `읽씹`을 빼고 `톡`을 넣는다.
- 대안 2(`답장 하나에 설레는 메신저 연애`): `답장`·`메신저`를 빼고 `톡`·`썸`을 넣는다.

**고를 때 기준**
- 한 단어씩. "연애게임"처럼 이름·부제 단어를 붙인 조합은 Apple이 이름+키워드를 합쳐 이미 찾아 준다.
- 남녀 양쪽(썸남/썸녀, 남친/여친)을 다 넣어 성별 선택 게임임을 살렸다.
- 출시 후 App Store Connect 분석에서 노출이 없는 단어는 `연애상담`, `대화`, `텍스트게임`, `오토메` 등으로 바꿔 본다.

작은 기종에는 자동으로 줄여 쓴다. **완료(2026-09-22):** `docs/store_screenshots/promo/01~08.png`(1320×2868, 문구 포함)를 올린다. 원본은 `raw/`,

## 7. 카테고리와 연령 등급

### 카테고리
- **기본: 게임 → 하위 카테고리 1 시뮬레이션, 하위 카테고리 2 어드벤처.** 텍스트 선택형 연애 게임은 두 곳 모두에서 찾는다.
- **보조 카테고리: 엔터테인먼트.**
- "소셜 네트워킹"이나 "라이프스타일"은 쓰지 않는다(실제 사람과 대화하는 앱으로 오해해 반려·오검색 위험).

### 연령 등급 설문 답 (App Store Connect → 앱 정보 → 연령 등급)

`assets/story/` 전체를 검색해 확인한 결과로 답했다.

| 항목 | 답 | 근거 |
|---|---|---|
| 만화 또는 판타지 폭력 | 없음 | |
| 사실적 폭력 / 장시간의 사실적 폭력 | 없음 | |
| 성적인 내용 또는 노출 | 없음 | 키스·스킨십·노출 장면 없음 |
| 성인/선정적 테마 (Mature/Suggestive Themes) | **드물게/경미** | 연애·썸·고백·질투가 주제. 선정적 묘사는 없음 |
| 비속어 또는 저속한 유머 | **드물게/경미** | 욕설 문장은 없고 "같이 욕한다" 같은 언급과 흑역사 개그 정도 |
| 알코올, 담배, 약물 사용 또는 언급 | **드물게/경미** | 술자리 언급 1회, "치킨 한 마리와 맥주 두 캔" 1회, 캐릭터 취향 태그 "술". 미니게임 id `drink_limit`은 이름만 남은 것으로 실제 내용은 "선 지키기"(드립 조절)이며 음주와 무관 |
| 공포/무서운 테마 | 없음 | |
| 의료/치료 정보 | 없음 | 의사 캐릭터가 있으나 의료 정보 제공 없음 |
| 모의 도박 | **없음** | 도박 게임 없음. 일상 이벤트 하나("소액 로또", 잔돈으로 산 로또 5등 서술 1줄)는 이야기 속 언급일 뿐 플레이어가 베팅하지 않음 |
| 실제 도박 / 콘테스트 | 없음 | |
| 무제한 웹 접근 | 없음 | |
| 사용자 생성 콘텐츠 / 사용자 간 메시지 | 없음 | 모든 대화는 미리 쓰인 가상 캐릭터와의 선택지. 플레이어 이름 입력만 있고 외부로 전송되지 않음 |
| 랜덤 보상 상품(루트 박스) 유료 판매 | 없음 | 인앱 결제 없음 |
| 광고 | 있음 | 전면·보상형 광고(AdMob). 설문에 광고 문항이 있으면 "예" |
| 연령 확인·보호자 통제 기능 | 없음 | |

- 예상 등급: **12+ (새 체계에서는 13+)** — 선정적 테마·알코올 언급이 "드물게/경미"라서. 4+나 9+로 낮추려고 답을 줄이지 않는다
  (심사에서 연애 소재가 보이면 반려된다).
- AdMob 최대 광고 콘텐츠 등급 T(Teen)와도 맞다(`RELEASE_CHECKLIST.md` §2).
- "아동용 앱(Kids 카테고리)"은 선택하지 않는다.
- 한국 스토어의 게임 등급은 Apple의 자체등급분류로 이 설문에서 정해진다. 별도 게임물관리위원회 신청은 필요 없다.

## 8. 제출 전 글자 수 다시 세기

문구를 고쳤으면 붙여 넣기 전에 센다(공백 포함, 한글 1자 = 1자).

```bash
python3 -c "import sys; t=sys.stdin.read().rstrip('\n'); print(len(t))" <<'EOF'
여기에 문구 붙여 넣기
EOF
```

제한: 부제 30 · 프로모션 텍스트 170 · 설명 4000 · 키워드 100 · 새로운 기능 4000.
