# 04. 마이크로 인터랙션 — "진짜 폰처럼"

> 2026-09-23. OVERHAUL_PLAN.md §0 C·D 피드백("실제 같지 않다", "텍스트만이라 집중이 안 된다")에 대한
> 연출 답안. **새 스토리·그림 없이**, 문자와 전화가 실제 폰에서 오는 것처럼 느껴지게 하는 작은 순간들.
> 기준: DESIGN_SYSTEM.md §1.10 `AppMotion`, §2.3, §4.1(테스트 고정 문구). 코드는 건드리지 않았다.

## 0. 원칙

1. **화면당 강조 연출 하나.** 나머지는 페이드·12pt 이내 이동만. 강조 자리: 알림 화면=카드 낙하,
   채팅=결과 패널 팝(크리티컬만), 전화=펄스 링, 날짜 카드=D+N 스케일, 엔딩=등급 pill.
2. **반복 애니메이션 금지 유지.** 타이핑 점이 계속 깜빡이지 않는다(`_TypingBubble` 주석). 대신
   *상태가 바뀌는 순간*(나타남·사라짐·다시 나타남)으로 살아 있음을 말한다.
3. **소리·진동은 "일이 생겼다"에만.** 말풍선 한 줄마다 울리지 않는다. 문자 도착·전화·보내기·
   날짜·결과·엔딩, 여섯 사건. 효과음 파일도 8개 이하(§C 예산).
4. **동작 줄이기**(`AppMotion.reduced`)면 모션은 0ms, 햅틱은 1회로 축소, 소리는 유지.
   진동·효과음 토글은 별도(§3). 무음 스위치를 존중한다.
5. **테스트 고정 문구는 그대로**: `'…'`, `'읽음 · N초째 답이 없다'`, `'전화가 왔어요'`, `'…(침묵)'`,
   `'부재중 전화 · 이름'`. 연출은 문구 주변에서만.

## 2. 상위 6개 정밀 명세

### 2.1 문자 도착 — 알림 카드 낙하 (#1)
- **트리거**: `EventScreen._syncEvent` 에서 `fresh && _previewName(ev) != null` 로 `_previewOpen = true` 가 되는 프레임.
- **소유**: 소리·햅틱은 `EventScreen`(부수효과를 화면 상태 전환과 한곳에 둔다). 슬라이드는 `NotificationPreview` 그대로.
- **타임라인**: t=0 `msg_in` + `mediumImpact` → 카드 슬라이드 `dSlow`, 커브 `standard` → `emphasized` 로 교체
  (`Offset(0,-1.4)` 시작은 유지, easeOutBack 이 끝에서 살짝 되튐 = "툭 내려앉음"). t=1.8s(`autoOpen`) 카드가
  `Offset(0,-0.3)` 으로 `dBase` 페이드 아웃 뒤 대화 열림.
- **동작 줄이기**: 알림 화면 자체를 건너뛰는 현행 유지. 단 `msg_in` 과 햅틱 1회는 대화가 열리는 순간 그대로 낸다.
- **주의**: 카드 위젯은 부수효과 없이 유지해 위젯 테스트가 오디오 플러그인 없이 돌게 한다.

### 2.2 전화 벨 — 링과 진동의 동기 (#2)
- **트리거**: `_callStage == CallStage.ringing` 진입. **정지**: `_acceptCall`, `_declineCall`, `dispose`,
  `AppLifecycleState.paused`, 되돌리기로 재진입 시 재시작.
- **소유**: `EventScreen` 에 `_ringTimer`(`Timer.periodic(PulseAvatar.period)`). `PulseAvatar` 는 그리기만.
- **타임라인**: 주기 1600ms 마다 `heavyImpact` → 120ms → `heavyImpact`(폰 벨의 "부르르-부르르"). 링 하나가
  새로 퍼지는 시점(`t=0`)과 맞춘다. `ring` 은 `ReleaseMode.loop`, 볼륨 0.6. 진동은 20초 뒤 자동 종료(링·소리는 계속) —
  방치했을 때 짜증·배터리를 막는다.
- **동작 줄이기**: 링 정지 1개(현행) + 진동은 첫 2주기만. 소리는 유지.
- **설정**: 진동 꺼짐이면 햅틱 전부 생략, 효과음 꺼짐이면 `ring` 생략 — 그래도 링 펄스는 남아 "전화" 로 읽힌다.

### 2.3 타이핑 "쓰다 지움" (#3)
- **트리거**: `_scheduleReveal` 에서 다음 줄이 `them` 이고, (a) 이 이벤트에서 아직 한 번도 안 했고
  (b) 대사 길이가 이벤트 내 `them` 줄 중 가장 길거나 직전 줄이 `wait` 일 때. 이벤트당 최대 1회.
- **소유**: 타이밍은 `EventScreen._scheduleReveal`. 말풍선 등장·퇴장은 `_TypingBubble` 을 `AnimatedSwitcher`
  (`AppMotion.fast(context)`, 페이드만)로 감싼 ListView 항목이 맡는다.
- **타임라인**: `…` 표시 → 700ms → `…` 퇴장(`dFast` 페이드) → 600ms 빈 상태 → `…` 재등장(`dFast`) → 800ms → 대사.
  총 +1.3s(1회). 일반 `them` 지연은 800ms 고정 대신 `clamp(600 + 글자수×18, 800, 2400)ms` — 긴 말은 오래 친다.
- **동작 줄이기**: 멈춤 없이 지연만 적용(현행 `disableAnimations` 분기 유지). `'…'` 문구·타입 불변(§4.1).

### 2.4 읽음 표시 (#4)
- **트리거**: `c.choose` 뒤 `lastOutcome != null && _picked != null` 로 내 말풍선이 그려진 프레임.
- **소유**: `EventScreen._syncReply` 에 `_readShown` 플래그와 타이머 추가. 표시는 새 `_ReadMark`(내 말풍선 아래 오른쪽 정렬,
  `labelSmall`, `tokens.systemLine`, 글자 `읽음`). 숫자 배지·노란 "1" 은 쓰지 않는다(§4.3 트레이드드레스).
- **타임라인**: t=0 보내기 → 500ms `읽음` 페이드 인(`dFast`) → 400ms 뒤 `_TypingBubble` → 이후 750ms 간격 반응(현행).
  결과가 실패 톤이면 `읽음` 을 1500ms 로 늦춘다 — "읽고 고민했다" 를 숫자 없이 전한다. 통화 화면(`isCall`)에는 없음.
- **동작 줄이기**: `읽음` 즉시, 간격 0. 되돌리기로 `lastOutcome` 이 null 이 되면 함께 사라진다.

### 2.5 보내기 슉 (#5)
- **트리거**: `_ChoicePanel._pick` → `onPicked(...)` 직전.
- **소유**: `selectionClick` + `msg_out` 은 `_pick`. 눌림은 `ChoiceButton` 의 기존 잉크에 `dInstant` 스케일 0.98 추가.
  내 말풍선은 `ChatBubble(mine)` 의 `_Entrance` 오프셋을 6→12pt 로(상대는 6pt 유지 — 보낸 쪽이 더 "던진다").
- **타임라인**: t=0 클릭 햅틱·`msg_out` → 눌린 버튼 0.98 `dInstant` → 패널이 `dBase` 로 내려가며 동시에 내 말풍선 `dBase` `standard` 상승.
- **동작 줄이기**: 모션 0, 햅틱·소리 유지. 미니게임 선택지는 미니게임 결과가 돌아온 뒤에 같은 연출.

### 2.6 날짜 카드 D+N (#6, 계획 B 연출)
- **트리거**: `SummaryScreen` `'다음 날로'` → (전면광고 뒤) → 새 `DayCardScreen` → 룰렛 시트. 첫날은 인트로와 합침(계획 B).
- **소유**: `DayCardScreen`(StatefulWidget, `CallBackdrop` 재사용). `GameController` 는 모른다.
- **타임라인**: t=0 `lightImpact` + `day_turn`, `D+N`(`displayLarge` 급 numeric) 스케일 0.9→1 + 페이드 `dSlow` `emphasized`
  → t=`dBase` 요일·날씨·장 이름 `labelLarge` 페이드 `dBase` → t=1.4s 전체 `dBase` 페이드 아웃 → 룰렛. 어디든 탭하면 즉시 아웃.
  **이 화면의 강조는 D+N 하나.** 배경 파티클·빛번짐 없음.
- **동작 줄이기**: 페이드만, 1.0s 유지 후 종료. 탭 스킵 동일.

## 3. 설정 토글 (계획 C 와 합침)

| 항목 | 기본 | 영향 |
|---|---|---|
| 효과음 | 켬 | §1 소리 열 전부. 무음 스위치는 항상 우선(`AudioContext` ambient) |
| 진동 | 켬 | §1 햅틱 열 전부. 꺼도 링 펄스·읽음·타이핑은 남는다 |
| 대사 속도 `보통 / 빠르게` | 보통 | 빠르게 = 타이핑 지연 ×0.5, "쓰다 지움" 생략, 읽음 간격 0. 재플레이 유저용 |
| (시스템) 동작 줄이기 | OS | 모션 0ms, 햅틱 1회로 축소. 앱 안에 중복 스위치는 두지 않는다 |

## 4. 하지 않는 것
- 말풍선마다 소리. 화면 흔들기(실패 포함). 상시 반복 애니메이션 추가. 카톡식 노란 "1"·꼬리 말풍선.
- 벨을 사용자가 끌 수 없는 상태로 두기. 알림 카드에 부수효과 심기(테스트 격리).
