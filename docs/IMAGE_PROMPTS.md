# 이미지 생성 프롬프트 (ChatGPT 이미지 생성용)

docs/IMAGE_PLAN.md 의 "이미지를 더 넣을 자리"마다 ChatGPT 에 그대로 붙여 넣는 프롬프트 모음이다.
캐릭터 초상화 12장(assets/portraits)은 docs/PORTRAIT_PROMPTS.md 에 따로 있다.

**작업은 이 문서 대신 그림 작업판에서 하는 게 빠르다**: https://claude.ai/artifact/QNfYdmSFKnfLkdi8P5mTi9
(캐릭터별 대화 묶음, 프롬프트 복사·저장 이름 복사·완료 체크. 프롬프트를 고치면 `python3 tool/image_studio/build.py` 로 다시 만든다.)

## 파일별 문서

| 순위 | 종류 | 문서 | 장 수 | 크기(ChatGPT 비율) | 저장 위치 |
|---|---|---|---|---|---|
| 1 | 엔딩 일러스트 | [image_prompts/01_endings.md](image_prompts/01_endings.md) | 60 | 세로 1024×1536 | `assets/endings/<엔딩 id>.png` |
| 2 | 사진 메시지 | [image_prompts/02_photos.md](image_prompts/02_photos.md) | 64 | 정사각 1024×1024 | `assets/photos/<이벤트 id>.png` |
| 3 | 아침 행동 배경 | [image_prompts/03_scenes_and_more.md](image_prompts/03_scenes_and_more.md) §1 | 6 | 가로 1536×1024 | `assets/scenes/<행동 id>.png` |
| 4 | 캐릭터 표정 | 같은 문서 §2 | 36 | 정사각 1024×1024 | `assets/expressions/<캐릭터 id>_<표정>.png` |
| 5 | 홈 키 아트 | 같은 문서 §3 | 1 | 가로 1536×1024 | `assets/keyart/home.png` |

파일 이름은 **영문 소문자 id + `.png`** 그대로다. 앱은 파일 이름으로 그림을 찾는다(id 가 틀리면 안 뜬다).
ChatGPT 가 내려 주는 PNG 를 이름만 바꿔 넣으면 된다. 용량이 크면 §4 대로 줄인다.

> 지금 코드에 연결된 것은 초상화뿐이다. 나머지 폴더는 그림이 준비되는 대로 불러오는 코드를 붙인다
> (초상화와 같은 방식: 파일이 있으면 쓰고, 없으면 지금 화면 그대로). 그림을 먼저 모아 두어도 앱은 깨지지 않는다.

## 1. 모든 프롬프트에 공통으로 지키는 규칙

1. **주인공(플레이어)은 얼굴을 그리지 않는다.** 플레이어는 남녀 누구나 될 수 있다.
   1인칭 시점(내 손·소매만 보이게), 뒷모습, 화면 밖으로 처리한다. 프롬프트에 이미 들어 있다.
2. **캐릭터가 나오는 그림은 그 캐릭터 초상화를 첨부한다.** `assets/portraits/<id>.jpg` 를 ChatGPT 에
   올리고 프롬프트를 붙여 넣는다. 프롬프트 첫 줄이 "첨부한 인물과 같은 사람"을 요구한다.
   캐릭터 컷에는 캐릭터가 한 명만 나온다(두 명을 한 장에 그리면 얼굴이 섞인다).
3. **글자를 그림 안에 넣지 않는다.** 간판·화면·종이의 글씨는 알아볼 수 없는 흐린 모양으로.
   (한글이 깨져 나오고, 앱이 문구를 따로 얹는다.)
4. **실존 상표·로고를 넣지 않는다.** 휴대폰·음료·게임 화면 모두 무상표.
5. **화풍 블록**은 매 프롬프트 맨 끝에 이미 붙어 있다. 고치지 말고 그대로 쓴다:

```
화풍: 한국 로맨스 웹툰의 한 장면 같은 깔끔한 반실사 디지털 일러스트. 선명한 이목구비, 맑고 매끈한 피부,
윤기 있는 머릿결. 가는 외곽선, 부드러운 셀 채색, 따뜻하고 부드러운 조명, 파스텔 톤. 글자·로고·워터마크 없음.
```

## 2. 한 장 만드는 순서

1. ChatGPT **새 대화**를 연다(대화가 길어지면 화풍이 흔들린다. 10장마다 새 대화).
2. 캐릭터 컷이면 초상화를 첨부한다. 크기는 프롬프트 첫 줄 `[세로 2:3]` 등으로 이미 지정돼 있다.
3. 프롬프트 블록을 통째로 붙여 넣는다.
4. 마음에 안 들면 §3 의 수정 문장을 이어서 보낸다.
5. PNG 를 내려받아 표의 이름으로 바꾼다.

## 3. 자주 쓰는 수정 문장

- 얼굴이 초상화와 다를 때: `첨부한 인물의 얼굴형·눈매·머리 모양을 그대로 유지해서 다시 그려 주세요. 표정과 장면만 바꿉니다.`
- 주인공 얼굴이 나왔을 때: `주인공의 얼굴이 보이면 안 됩니다. 1인칭 시점으로 손과 소매만 보이게 다시 그려 주세요.`
- 글자가 생겼을 때: `그림 안의 글자·숫자·로고를 모두 지우고 흐린 무늬로 바꿔 주세요.`
- 너무 어둡거나 칙칙할 때: `전체를 한 단계 밝게, 파스텔 톤으로. 그림자는 부드럽게.`
- 너무 실사 같을 때: `사진처럼 말고 웹툰 일러스트로. 외곽선을 가늘게 살려 주세요.`
- 캐릭터가 화면 가운데에 너무 작을 때: `인물을 더 가깝게, 허리 위 상반신이 화면의 절반을 차지하게.`

## 4. 파일 크기

ChatGPT PNG 는 한 장에 2~4MB 다. 180장이면 앱이 너무 커지므로 넣기 전에 줄인다(macOS):

```sh
# 엔딩·위기 컷(세로): 긴 변 1350px
sips -Z 1350 assets/endings/*.png
# 사진 메시지·표정: 1024 → 768px
sips -Z 768 assets/photos/*.png assets/expressions/*.png
# 배경·키 아트(가로): 긴 변 1200px
sips -Z 1200 assets/scenes/*.png assets/keyart/*.png
```

PNG 로 두어도 된다(앱은 png·jpg 둘 다 읽는다). 전체 용량이 40MB 를 넘으면 그때 JPG 로 바꾼다.
