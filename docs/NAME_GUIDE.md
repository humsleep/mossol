# 이름 부르기 — 작가 가이드 (2026-09-20)

플레이어가 새 게임 이름 단계("뭐라고 불러 드릴까요?")나 설정 › 내 이름에서 이름을 적으면, 캐릭터가 대사에서
그 이름을 부른다. 이 문서는 **기존 대사에 이름을 넣는 작가**가 따를 규격이다. 엔진은
`lib/engine/text_template.dart`, 입력 규칙은 `lib/engine/player_name.dart` 에 있다.

한 줄 요약: **이름은 드물게, 관계가 움직이는 순간에만. 이름이 없는 사람에게도 자연스러운 문장으로.**

---

## 1. 자리표시자 규격

대사 문자열 안에 `{name…}` 을 쓴다. 화면에 나가기 직전에 이름으로 바뀐다(세이브에는 원문이 남는다).

| 쓰는 법 | 뜻 | 민석(받침) | 민수(받침 없음) | 하늘(ㄹ 받침) | 이름 없음(기본값) |
|---|---|---|---|---|---|
| `{name}` | 이름 그대로 | 민석 | 민수 | 하늘 | 너 |
| `{name\|아야}` | 부를 때(호격) | 민석아 | 민수야 | 하늘아 | *(지워짐, 쉼표 정리)* |
| `{name\|이가}` | 주격 | 민석이 | 민수가 | 하늘이 | 네가 |
| `{name\|은는}` | 보조사 | 민석은 | 민수는 | 하늘은 | 너는 |
| `{name\|을를}` | 목적격 | 민석을 | 민수를 | 하늘을 | 너를 |
| `{name\|과와}` | 공동격(글말) | 민석과 | 민수와 | 하늘과 | 너와 |
| `{name\|이랑랑}` | 공동격(입말) | 민석이랑 | 민수랑 | 하늘이랑 | 너랑 |
| `{name\|으로로}` | 방향·자격 | 민석으로 | 민수로 | **하늘로** | 너로 |
| `{name\|이}` | 친근한 '이' | 민석이 | 민수 | 하늘이 | 너 |
| `{name\|씨}` | 존칭 | 민석 씨 | 민수 씨 | 하늘 씨 | 그쪽 |
| `{name\|씨+이가}` | 존칭 + 조사 | 민석 씨가 | 민수 씨가 | 하늘 씨가 | 그쪽이 |

- **친근한 '이'** 는 뒤에 조사·어미를 직접 붙인다: `{name|이}랑`(민석이랑/민수랑), `{name|이}가`(민석이가/민수가),
  `{name|이}는`, `{name|이}야`(서술: 민석이야/민수야), `{name|이}잖아`, `{name|이}라고`.
  친구·동창처럼 이름을 편하게 부르는 캐릭터가 문장 속에서 이름을 말할 때 쓴다.
- `씨` 뒤에는 `+` 로 조사 하나를 더 붙인다: `{name|씨+은는}`, `{name|씨+을를}`, `{name|씨+이랑랑}`.
- 조사 자리에 쓸 수 있는 것: `아야 이가 은는 을를 과와 이랑랑 으로로`(끝에 하나) 와 `이 씨`(맨 앞에 하나).
  호격 `아야` 는 `이`·`씨` 와 섞지 않는다. 그 밖의 조사(`에게`, `한테`, `도`, `의`, `만`)는 받침과 무관하므로
  `{name}한테`, `{name}도` 처럼 **그냥 뒤에 적는다**.

### 1.1 이름이 없을 때: 대체어

플레이어가 이름 단계를 건너뛰면 이름이 없다. 모든 자리표시자는 이름 없이도 문장이 되게 써야 한다.

- **세 번째 칸이 대체어다**: `{name|아야|자기}` → 이름 없으면 `자기야`. 조사는 대체어에 맞춘다
  (`{name|은는|선배}` → `선배는`, `{name|이가|나}` → `내가`).
- **대체어를 비우면 통째로 지운다**: `{name|아야|}`, `{name||}`. 옆의 쉼표·공백도 정리한다
  (`{name|아야|}, 자?` → `자?`, `잘 자, {name|아야|}.` → `잘 자.`).
- **대체어를 안 적으면 기본값**:
  - 호격 `{name|아야}` → 지운다(위와 같다). 이름을 부르던 자리가 조용히 빠진다.
  - `씨` 가 붙은 것 → `그쪽`. (지우의 "그쪽이랑 똑같이 생긴 사람" 과 같은 호칭)
  - 그 밖 → `너` + 조사. `너` + `이가` 는 `네가`(`나`→`내가`, `저`→`제가` 도 같다).
- 존댓말 캐릭터가 `{name}` 을 문장 속에 쓰면 기본값 `너` 가 나간다. **존댓말 캐릭터는 꼭 대체어를 적거나
  `씨` 를 쓴다.** 예: `{name|씨|}, 오늘 고마웠어요` → 이름 없으면 `오늘 고마웠어요`.
- `{name|이}` 뒤에 `가`·`는`·`를` 을 직접 붙일 때 대체어는 **받침 없는 말**(너, 자기)이어야 한다. 받침 있는 말
  (`그쪽`)은 `그쪽이가` 가 된다. 필요하면 `{name|이가|그쪽}` 처럼 조사를 자리표시자 안에 넣는다.

### 1.2 받침 판단

- 한글: 마지막 음절의 받침. ㄹ 받침은 `으로로` 에서만 받침 없음처럼 `로`.
- 숫자로 끝나는 이름: 한국어로 읽은 소리(1 일·7 칠·8 팔 → ㄹ, 3 삼·6 육·0 영 → 받침, 2·4·5·9 → 없음,
  10 십·100 백·1000 천 → 받침). `민수7아`, `민수7로`, `민수9를`.
- 영문 이름: 발음 추정. `l`·`le` → ㄹ(Paul로), `m`·`n`·`ng`·`me`·`ne` → 받침(Tom아, Jane이),
  모음 하나 뒤의 `b p t k` 와 `ck` → 받침(Bob을, Jack은), 그 밖(모음, `r`, `rk`, `d`, `s`, `x`…) → 없음
  (Mina야, Peter를, Mark는). 틀릴 수 있다. 영문 이름에 조사가 어색하게 붙는 것을 줄이려면 영문 이름이 올 만한
  자리에서 **조사가 필요 없는 문장**(`{name|아야}` 대신 `야 {name}`)을 고른다.

### 1.3 입력 규칙과 길이

- 이름: 1~6자, 한글 완성형·영문·숫자, 띄어쓰기 없음. 욕설·혐오 표현 기본 목록은 막는다.
- 대사 길이 제한(반응 60자, 알림 40자, 사진 캡션 20자, 서사 신호 40자)은 **가장 긴 이름(6자)으로 바꾼 결과**로 잰다.
  `{name|아야}`(9자)는 화면에서 최대 7자라 원문보다 짧다. 대체어가 길면 대체어 쪽으로 잰다.
- 형식이 틀리면(모르는 조사, 닫히지 않은 `{`, 짝 없는 `}`) 검증기(`StoryBundle.validate`)가 앱 시작 전에 막는다.
  중괄호는 자리표시자에만 쓴다.

### 1.4 쓸 수 있는 곳 · 없는 곳

| 쓸 수 있다 (치환됨) | 쓸 수 없다 (검증기 오류) |
|---|---|
| 이벤트 `lines[].text`, 사진 `photo.caption`, `title` | 엔딩 `name`(앨범 제목) |
| 선택지 `text`, `reply` / `failReply` / `critReply` | 효과의 `album`(흑역사 제목) |
| `preview`(알림), `cliffhanger` | 캐릭터 `name`, `tagline` |
| 엔딩 `epilogue`, `hint` | |
| 캐릭터 `firstLine`(캐스트 소개 첫 메시지) | |
| `signals.json` 문장 | |

선택지 `text` 는 **플레이어가 하는 말**이다. 플레이어가 자기 이름을 부를 일은 거의 없으니, 선택지에는 3인칭 소개
(`"{name|이}라고 해요"` 류) 말고는 쓰지 않는다. 엔딩 에필로그와 서사 신호는 **1인칭 서술**("나를")이라 이름은
따옴표 안 대사에서만 쓴다: `서연이 "{name|아야}" 하고 불렀다.`

## 2. 어디에 넣으면 효과가 큰가

이름은 **호칭이 바뀌는 신호**다. 매번 부르면 소음이 되고, 한 번 부르면 사건이 된다.
기준: **캐릭터 한 명당 루트 전체에서 8~15줄**, 한 이벤트에 1줄(많아도 2줄). 100~200줄 작업이면 12명 × 10줄 안팎이다.

1. **첫 연락** (`<id>_r00`·`r01`, 캐스트 소개 `firstLine`): "이 사람이 나를 안다" 는 순간.
   `@신입` 대신 `@{name}`, `혹시 {name}?` 처럼 **처음 알아보는 장면**. 온라인 친구는 예외(닉네임으로 시작한다).
2. **호칭이 바뀌는 순간**: 회원님 → 너(유나 r08, 도윤 r09), 존댓말 → 반말(다은 r07), 닉네임 → 실명(민재 r09~r10,
   소희 r09 야시장). 이 순간에 이름을 처음 부르면 효과가 가장 크다. 예: 유나 r08 `회원님 말고… {name|아야}. 이렇게 불러도 돼?`
3. **고백·결정** (`r15`, 좋은 엔딩 직전 선택의 `critReply`): 이름을 부르고 한 박자 쉬는 문장.
   `{name|아야}.` 한 줄을 따로 두는 것이 가장 강하다.
4. **전화 첫마디** (`mo_*_call_*` 첫 줄, 받기 직후 자막): `…자?` → `…{name|아야}, 자?`. 목소리로 이름을 듣는 느낌.
   통화마다 넣지 말고 캐릭터당 전화 한 통에만.
5. **엔딩**: 좋은·행복 엔딩 에필로그의 인용 대사 한 번. `…"{name|아야}, 가자." 선배가 먼저 걸었다.`
6. **위기에서 이름을 부르는 순간**: 사흘째 답 없음(`r12`), 부상·쓰러짐(유나 r12, 도윤 r10), 들켰을 때(`r13`).
   급할 때 사람은 이름을 부른다. `{name|아야}! 괜찮아?` 는 되고, `{name|아야}, 그거 알아?` 같은 잡담은 약하다.
7. **알림 미리보기**(`preview`): 잠금화면에 이름이 뜨는 것은 강한 연출이다. 캐릭터당 한 번까지.

## 3. 넣지 말아야 할 곳

- **모든 대사에 남발 금지.** 한 이벤트에 3번 이상, 연속 두 줄에 이름을 쓰지 않는다.
- **이미 호칭 관계가 확립된 경우.** 도윤·유나가 "회원님" 으로 부르는 구간(r08·r09 전), 주인공이 "선배" 로
  불리는 장면(정우 r14 신입 대사처럼 후배가 주인공을 부르는 경우)은 그 호칭이 곧 관계다. 이름으로 바꾸지 않는다.
- **캐릭터 말투상 이름을 안 부르는 캐릭터·구간.** 지우·승현은 끝까지 호칭 없이 존댓말을 쓴다 — 이름은 결정적인
  순간 한두 번, 반드시 `{name|씨|}` 로. 다은은 반말 전환 전에는 부르지 않는다.
- **조연 대사**(태현·준호·엄마들·신입)에는 넣지 않는다. 캐릭터와 주인공 사이의 일이다.
  예외: 서연 r00 단톡 호명처럼 **캐릭터가 여럿 앞에서 부르는** 장면.
- **내레이션**(`who: narr`)과 시스템 줄에는 넣지 않는다. 주인공 시점이라 자기 이름을 서술하지 않는다.
- 닉네임이 관계의 일부인 곳(건우의 `'우유'`, 소희가 닉네임을 줄여 부르는 것)은 닉네임을 지킨다.
  이름은 닉네임을 넘어서는 한 번에만 쓴다: 건우 `우유… 아니, {name|아야}.`
- 오빠·누나·형·언니와 섞지 않는다(주인공은 성별 중립, CAST_BIBLE §0.3).

첫 번째 선택이다.

## 5. 작업 순서와 점검

1. 캐릭터 한 명씩, §2 의 1~7 순서로 후보 줄을 고른다. 캐릭터당 8~15줄.
2. 자리표시자를 넣고, **이름 없음 문장을 소리 내 읽는다**(대체어가 자연스러운가).

## 6. 엔진 참고 (작가는 몰라도 된다)

- 이름은 기기 메타(`PlayerMeta.playerName`)에만 있다. 세이브에는 원문 대사만 남으므로 이름을 바꾸면 진행 중인
  회차도 다음에 그려지는 대사부터 새 이름이 나간다. 전체 초기화에서 지워진다. 기기 밖으로 보내지 않는다.
- 치환 지점: `GameController.say` / `shownEvent`(이벤트 사본) / `lastReply`, 정산·홈·행동의 클리프행어와 서사 신호,
  엔딩·앨범의 에필로그와 힌트, `StoryBundle.firstLineOf`. `keepAll`(단어 단위 줄바꿈)은 치환 **뒤에** 씌운다.
