# 캐릭터 초상화 프롬프트 (ChatGPT 이미지 생성용)

모쏠 키우기 12명의 프로필 이미지를 ChatGPT 이미지 생성으로 만들 때 그대로 복사해 쓰는 문서다.
그림을 `assets/portraits/<id>.png` 로 넣으면 앱이 알아서 이니셜 원 대신 그림을 보여 준다(코드 수정 없음, §8).

- 근거: `docs/CAST_BIBLE.md`(신규 6명 외형 인상), `assets/story/characters.json`(역할·tagline),
  `events_route_a.json`·`events_route_b.json`(기존 6명 대사 속 단서: 지우의 노트북·시계·러닝,
  민재의 모자·헤드셋, 하늘의 앞치마, 예은의 편지, 도윤의 운동화·부상), `lib/ui/design_system.dart`의
  `characterAccents`(배경색).
- 등급 12+. 모두 **분명한 성인(20대 중반~후반)** 으로 그린다.
- 화풍만 바꾸면 실사로 교체할 수 있게, **공통 스타일 블록**과 **캐릭터 블록**을 나눴다. 캐릭터 블록에는
  화풍 단어를 넣지 않았다.

---

## 1. 쓰는 법 (요약)

1. ChatGPT 새 대화를 연다.
2. **§2 공통 스타일 블록 + §4 서연 블록**을 한 번에 붙여 넣는다. 마음에 들 때까지 다시 뽑는다.
   이 한 장이 12명 전체의 **화풍 기준**이 된다.
3. 같은 대화에서 **"방금 이미지와 같은 화풍·조명·구도·배경 처리로 다른 인물을 그려 주세요."** 한 줄 +
   §2 스타일 블록 + 다음 캐릭터 블록을 붙인다. 12명을 모두 같은 대화에서 만든다(§5).
4. 받은 이미지를 §7 체크리스트로 확인하고, §8 규격대로 줄여서 `assets/portraits/` 에 넣는다.
5. 앱을 **완전히 다시 빌드**해서(핫 리로드 X) 디버그 갤러리의 "초상화 12명 미리보기"로 확인한다(§9).

## 2. 공통 스타일 블록 (모든 프롬프트 맨 앞에 붙인다)

```
[스타일 — 일러스트]
한국 웹툰·모바일 연애 게임 프로필 스타일의 깔끔한 반실사 디지털 일러스트로 그려 주세요.
선: 가늘고 깨끗한 외곽선, 선 굵기 일정, 거친 스케치 선 없음.
채색: 부드러운 셀 채색에 가벼운 그라데이션, 피부는 맑고 자연스럽게(과한 광택·과한 보정 없음), 채도는 중간.
조명: 왼쪽 위에서 들어오는 따뜻하고 부드러운 자연광, 얼굴에 은은한 림라이트, 강한 그림자 없음.
구도: 가슴 위 상반신, 몸은 정면에서 15도쯤 비스듬히, 얼굴과 시선은 거의 정면(보는 사람을 향함).
얼굴 위치: 얼굴이 가로 가운데, 세로로는 위쪽 1/3 지점. 머리 꼭대기 위로 여백을 조금 남기고,
정사각형 안에 내접하는 원으로 잘라도 머리카락·얼굴·귀가 잘리지 않게.
배경: 아래에 적은 색의 단색 평면 배경. 무늬·소품·풍경·그림자 없음, 가장자리까지 같은 색.
비율과 크기: 1:1 정사각형, 1024×1024.
인물은 한 명. 분명한 성인. 건전하고 단정한 차림.
넣지 말 것: 글자, 숫자, 말풍선, 로고, 브랜드 표시, 워터마크, 서명, 테두리 프레임, 다른 사람, 동물.
```

### 2.1 실사로 바꾸려면 — 위 블록 대신 이 블록을 붙인다

캐릭터 블록(§4)은 그대로 두고 스타일 블록만 바꾼다. 구도·배경·금지 항목은 같으므로 앱 쪽 원형 크롭도 그대로 맞는다.

```
[스타일 — 실사]
자연스러운 실사 인물 프로필 사진처럼 만들어 주세요. 85mm 렌즈, 조리개 f/2.8 느낌의 얕은 심도,
스튜디오의 부드러운 창가 조명(왼쪽 위에서 따뜻하게), 과한 보정·과한 피부 보정 없이 자연스러운 피부 결.
구도: 가슴 위 상반신, 몸은 정면에서 15도쯤 비스듬히, 얼굴과 시선은 거의 정면.
얼굴 위치: 얼굴이 가로 가운데, 세로로는 위쪽 1/3 지점. 머리 꼭대기 위로 여백을 조금 남기고,
정사각형 안에 내접하는 원으로 잘라도 머리카락·얼굴·귀가 잘리지 않게.
배경: 아래에 적은 색의 단색 무지 배경지(스튜디오 배경), 무늬·소품 없음.
비율과 크기: 1:1 정사각형, 1024×1024.
인물은 한 명. 분명한 성인. 건전하고 단정한 차림. 실존 인물이나 유명인을 닮지 않은, 가상의 평범한 한국인 얼굴.
넣지 말 것: 글자, 숫자, 로고, 브랜드 표시, 워터마크, 서명, 테두리 프레임, 다른 사람, 동물.
```

> 실사는 실존 인물 닮음 위험이 일러스트보다 훨씬 크다. §7의 역이미지 검색을 반드시 한다.
> 실사로 바꿀 때는 12장을 **한꺼번에** 바꾼다. 일러스트와 실사가 섞이면 한 게임처럼 보이지 않는다.

## 4. 캐릭터별 프롬프트 (스타일 블록 바로 뒤에 붙인다)

각 블록은 **§2 스타일 블록 + 아래 블록** 순서로 붙인다. 두 번째 캐릭터부터는 맨 앞에
`방금 이미지와 같은 화풍·조명·구도·배경 처리로 다른 인물을 그려 주세요.` 한 줄을 더한다.

### 4.1 여성 캐릭터 쪽

#### 서연 `seoyeon` — 동아리 선배

```
[인물]
20대 중반의 한국인 여성, 졸업을 앞둔 대학 동아리 선배. 갸름한 계란형 얼굴, 가늘고 살짝 올라간 긴 눈매, 옅은 쌍꺼풀.

표정: 웃음을 참는 듯 입술을 살짝 깨문 장난스럽고 여유 있는 미소, 눈은 웃고 있음. 무언가 놀리고 싶은 얼굴.
옷: 차콜색 오버사이즈 니트 카디건 안에 흰 라운드 티, 가는 은색 목걸이 하나.
소품: 반으로 접은 무지 전시회 팸플릿을 한 손에 가볍게 쥐어 가슴 아래에 둠(글자 없이).

```

## 5. 12장을 한 게임처럼 맞추는 법 (일관성 가이드)

1. **기준 한 장 먼저.** 새 대화에서 서연(§2 + §4 서연)으로 시작한다. 화풍·선·조명·얼굴 위치가 마음에 들 때까지
   다시 뽑는다. 여기서 확정한 한 장이 12명 전체의 기준이다.
2. **같은 대화에서 이어 간다.** 두 번째부터는
   `방금 이미지와 같은 화풍·조명·구도·배경 처리로 다른 인물을 그려 주세요.` + §2 스타일 블록 + 캐릭터 블록.
   추천 순서: 서연 → 정우 → 다은 → 하늘 → 지우 → 승현 → 소희 → 민재 → 예은 → 건우 → 유나 → 도윤
   (짝을 번갈아 그려야 성별이 달라도 화풍이 벌어지지 않는다).
3. **대화가 길어져 화풍이 흔들리면** 새 대화를 열고, 확정한 기준 이미지(서연)를 첨부해
   `첨부한 이미지의 화풍·선 굵기·채색·조명·구도·얼굴 크기와 위치를 그대로 따라서, 다른 인물을 그려 주세요. 첨부 이미지의 인물 얼굴은 따라 하지 마세요.`
   를 맨 앞에 붙인다. 이미 완성한 2~3장을 함께 올리면 더 안정적이다.
4. **다시 뽑을 때 바꾸면 안 되는 것**
   - §2 스타일 블록 전체(한 글자도 고치지 않는다. 고치면 12장을 다시 맞춰야 한다).
   - 구도(가슴 위, 15도), 얼굴 위치(가운데 위쪽 1/3), 1:1 비율, 단색 배경과 그 색 코드.
   - 캐릭터 블록의 헤어 색·길이·모양, 옷 색, 소품(§3 표의 구별 요소). 표정 문장은 다듬어도 된다.
5. **부분만 고칠 때**는 ChatGPT의 이미지 편집(영역 선택)으로 "이 부분만 ○○로" 고친다. 전체를 다시 뽑으면
   얼굴이 바뀐다. 손·소품 오류는 부분 편집이 가장 빠르다.
6. **손은 최소로.** 손이 크게 나오면 AI 오류(손가락 개수·관절)가 잦다. 소품은 가슴 아래에 살짝 보이게 적었고,
   그래도 손이 이상하면 `손이 화면 아래로 나가도록 조금 더 위에서 잘라 주세요.`를 붙인다.
7. **색 확인.** 배경이 캐릭터 색 코드와 크게 다르면 `배경을 #XXXXXX 단색으로만 바꿔 주세요.`로 편집한다.
   앱에서 원 바깥(강조색 container)과 그림 배경이 이어져 보이는 게 목표다.

## 6. 원형 크롭 규칙 (앱에서 어떻게 잘리는지)

- 앱은 정사각형 이미지를 **내접원**으로 자른다(가장자리 네 귀퉁이가 사라짐). 가장 큰 곳은 전화 화면 96pt,
  캐스트 소개 카드 72pt, 가장 작은 곳은 32pt(이어하기 카드·단톡 줄).
- 그래서 머리 꼭대기와 양쪽 귀가 원 안에 들어와야 하고, 소품은 원의 아래쪽 가운데에 있어야 보인다.
  32pt에서도 누구인지 알아보려면 **헤어 실루엣과 머리색**이 가장 중요하다(§3 표가 이걸 가른 이유).
- 가장자리에 강조색 1pt(전화 화면은 2pt) 테두리가 그림 위에 얹힌다. 배경을 강조색 계열로 두면 테두리가 자연스럽다.

## 7. 체크리스트 (한 장마다, 그리고 12장 모아서)

한 장마다:
- [ ] **상업적 이용 약관**: 이미지를 만들 때 쓴 ChatGPT 요금제·시점의 이용 약관에서 생성물의 소유권과 상업적 이용(앱 내 사용, 스토어 스크린샷)이 허용되는지 확인하고, 확인한 날짜와 약관 링크를 기록해 둔다.
- [ ] **실존 인물 닮음 없음**: 역이미지 검색(Google 렌즈, 네이버 스마트렌즈 등)으로 비슷한 실존 인물·연예인 사진이 나오지 않는지 확인. 닮았다고 느껴지면 얼굴형·눈매 문장을 바꿔 다시 뽑는다.
- [ ] **분명한 성인으로 보이는가**: 얼굴 비율·옷차림이 20대 중후반으로 보이는지. 앳되어 보이면 `조금 더 성숙한 20대 후반 얼굴로`를 붙여 다시 뽑는다.
- [ ] **선정성 없음**: 노출·몸매 강조 없음, 트레이너는 지퍼 올린 상의.
- [ ] **AI 오류**: 손가락 개수·관절, 눈동자 좌우 크기·방향, 귀걸이 짝, 안경테 끊김(정우), 헤드셋·청진기 구조, 이너 컬러 위치(소희), 머리끈·땋은 머리가 끊기지 않는지.
- [ ] **글자·로고 없음**: 옷, 앞치마, 서류, 게임 패드, 편지 봉투에 알아볼 수 있는 글자나 로고가 없는지(흐릿한 가짜 글자도 지운다).
- [ ] **원형 크롭 미리보기**: 원으로 잘랐을 때 머리 꼭대기·귀가 잘리지 않는지. 디버그 갤러리의 "초상화 12명 미리보기"에 원형 가이드 선이 있다(§9). 넣기 전에는 macOS 미리보기에서 정사각형 가운데 원을 눈으로 확인.
- [ ] **배경**: 단색이고 색 코드와 가까운지, 무늬·그림자가 없는지.

12장 모아서:
- [ ] 12장을 한 화면에 나란히 놓고(디버그 갤러리 맨 위 줄) 화풍·선 굵기·채도·밝기·얼굴 크기가 같은지.
- [ ] 같은 쪽 6명끼리 32pt 크기에서도 누가 누구인지 헤어 실루엣만으로 구별되는지.
- [ ] 라이트·다크 모드 둘 다에서 테두리와 그림이 어색하지 않은지(갤러리 상단 세그먼트로 전환).
- [ ] 히든 두 명(유나·도윤)은 공개 전 화면에서 실루엣으로 가려지는지(앱이 처리한다. 확인만).

## 8. 파일 규격과 넣는 법

| 항목 | 규격 |
|---|---|
| 경로 | `assets/portraits/<id>.png` (예: `assets/portraits/seoyeon.png`) |
| 파일 이름 | 캐릭터 id 그대로, **영문 소문자**. `seoyeon` `haneul` `jiwoo` `minjae` `yeeun` `doyun` `jeongwoo` `daeun` `seunghyun` `sohee` `geonwoo` `yuna` |
| 형식 | PNG 권장. JPG(`.jpg`/`.jpeg`)도 된다. 같은 id에 둘 다 있으면 PNG를 쓴다 |
| 크기 | 정사각형. 원본은 1024×1024로 보관하고, 앱에 넣는 파일은 768×768 권장(가장 큰 표시 96pt × 3배 = 288px의 2.5배 이상) |
| 용량 | 한 장 **200KB 이하** 권장(12장 합계 2.4MB 이하) |
| 하위 폴더 | 쓰지 않는다. `assets/portraits/draft/…` 는 무시된다 |

ChatGPT가 주는 PNG는 한 장에 1~2MB라 줄여서 넣는다. 원본은 저장소 밖(예: `~/Pictures/mossol_portraits/`)에 보관한다.
macOS 기본 명령 `sips` 만으로 된다.

```sh
# 원본 폴더에서 앱용 JPG 로 줄이기 (768px, 품질 80 → 보통 70~150KB)
cd ~/Pictures/mossol_portraits
for id in seoyeon haneul jiwoo minjae yeeun doyun jeongwoo daeun seunghyun sohee geonwoo yuna; do
  [ -f "$id.png" ] || continue
  sips -z 768 768 -s format jpeg -s formatOptions 80 "$id.png" \
    --out ~/workspace/mossol/assets/portraits/$id.jpg
done
ls -lh ~/workspace/mossol/assets/portraits

# PNG 로 넣고 싶으면 크기만 줄인다(용량은 JPG 보다 크다. 200KB 를 넘으면 JPG 로)
sips -z 768 768 seoyeon.png --out ~/workspace/mossol/assets/portraits/seoyeon.png

# 크기 확인
sips -g pixelWidth -g pixelHeight ~/workspace/mossol/assets/portraits/*.jpg
```

파일을 넣은 뒤 할 일:
- **코드·JSON 수정 없음.** `pubspec.yaml` 에 `assets/portraits/` 폴더가 이미 등록돼 있고, 앱이 시작할 때
  `AssetManifest` 를 읽어 `<id>.png|jpg` 가 있는 캐릭터만 그림으로 바꾼다. 없는 캐릭터는 이니셜 원 그대로다.
  몇 장만 먼저 넣어도 된다.
- 새 파일은 번들에 들어가야 하므로 **앱을 완전히 다시 실행**한다(핫 리로드·핫 리스타트로는 안 보일 수 있다).
  `flutter run` 을 끄고 다시 켜거나, 시뮬레이터용은 `flutter build ios --simulator --debug` 후 실행.
- `assets/portraits/.gitkeep` 은 지우지 않는다(빈 폴더여도 빌드가 깨지지 않게 하는 파일).

## 9. 넣은 뒤 앱에서 확인하는 순서

1. `flutter run --dart-define=MOSSOL_DEBUG_GALLERY=true` → 디버그 갤러리 → **초상화 → 초상화 12명 미리보기**.
   - 맨 위 "12명 중 N장 있음"으로 인식 여부 확인(0장이면 파일 이름·경로·재빌드를 확인).
   - 맨 위 줄: 12명 나란히(화풍 통일).
   - 캐릭터마다: 원본 정사각형 + 원형 가이드 선, 실제 크기 32·40·56·72·96, 히든은 미공개 실루엣.
   - 상단 세그먼트로 라이트·다크 전환.
2. 같은 갤러리에서 **새 게임 온보딩 → 2단계: 캐스트 소개**(여성·남성): 카드 아바타 72pt(320pt 폭 폰은 56pt).
3. **모먼트 미리보기 → 전화**: 수신 화면의 큰 원(96pt)과 통화 중 작은 원(40pt).
4. **정산·홈 미리보기**: 관계 변화 카드(40pt), 이어하기 카드(32pt), 홈 사람들 줄(40pt).
5. 실제 게임을 시작해 채팅 화면까지 한 번 본다(아래 "알려진 한계" 참고).
6. `flutter test test/widget/portrait_test.dart test/widget/layout_test.dart` 로 넘침이 없는지 확인.

알려진 한계: 채팅 화면 헤더의 작은 원(`event_screen.dart` 의 `_AvatarDot`)은 아직 이니셜이다. 그 파일은 다른 작업이
진행 중이라 이번 작업에서 건드리지 않았다. `CharacterAvatar(name:, characterId: ev.character, accent:, size: 32)` 로
바꾸면 같은 규칙으로 그림이 뜬다.
