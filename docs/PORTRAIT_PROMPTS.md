# 캐릭터 초상화 프롬프트 (ChatGPT 이미지 생성용)

모쏠 키우기 12명의 프로필 이미지를 ChatGPT 이미지 생성으로 만들 때 복사해 붙여 넣는 문서다.
그림을 `assets/portraits/<id>.jpg`(또는 `.png`)로 넣으면 앱이 이니셜 원 대신 그림을 보여 준다. 코드는 고치지 않는다(§8).

## 지금 바로 하는 순서

1. ChatGPT **새 대화**에 §2의 **여성 라인업 프롬프트**를 붙여 넣는다. 여섯 명이 **머리·옷을 가려도 얼굴만으로**
   구별될 때까지 §6의 수정 문장으로 고친다. 이 한 장이 여성 6명의 디자인 확정본이다. 이미지를 저장한다.
2. **같은 대화에서** §3의 단독 프로필 문장을 여성 6명 차례로 붙여 넣는다. 서로 닮아 가면 새 대화에
   라인업 이미지만 첨부해서 이어 간다(§3 맨 위).
3. **또 다른 새 대화**에서 남성 라인업으로 1~2를 반복한다.
4. 12장을 §7 체크리스트로 본다. 끝내 안 되는 사람만 §4의 개별 생성 프롬프트로 다시 뽑는다.
5. §8대로 768px JPG로 줄여 `assets/portraits/`에 넣고, 앱을 완전히 다시 빌드해 디버그 갤러리에서 확인한다.

## 0. 이번 판에서 바뀐 것과 이유

> **2026-09-21 2차 개정 — 매력 추가, 일러스트 전용.** 얼굴을 서로 다르게 만든 뒤, **여성은 예쁘게, 남성은 잘생기게**
> 보이도록 인물마다 `매력:` 줄을 넣었다(§1.7). 핵심은 **"다르게"와 "예쁘게"를 순서로 푸는 것**이다.
> 생김새(얼굴상·눈·코·입)를 먼저 못 박고, 매력은 **그 얼굴 안에서** 살리게 했다. "예쁜/잘생긴"만 단독으로 쓰면
> 모델이 기본 미형 얼굴 하나로 되돌아가기 때문이다(§1.6).
> 함께 바꾼 것: 못나 보이던 요소 완화(민재 짙은 다크서클·듬성 수염 → 옅은 다크서클·면도, 하늘 모공·수염 자국 삭제,
> 유나 잇몸·눈가 주름 삭제, 소희 앞니 "살짝"), 표정 3개 완화(소희 부릅뜬 외침 → 신난 외침, 건우 볼 불룩 → 입꼬리 말림,
> 도윤 미간 찡그림 → 다정한 걱정). 표정 12개가 모두 다르다는 원칙은 그대로다. 실사 화풍 블록은 뺐다.

> **2026-09-21 개정.** 지난 판(캐릭터마다 새 대화 + 긴 얼굴 묘사)으로 여성 캐릭터를 뽑아 보니 **눈매가 다 같아
> 같은 사람처럼** 보였다. 원인과 대응:
>
> 1. 반실사 웹툰풍 여성 얼굴은 모델의 **기본 미형 얼굴**로 강하게 끌려간다. 긴 묘사가 뒤쪽에 있으면 거의 무시된다.
>    → 프롬프트 **맨 앞**에 얼굴상과 눈을 두고, 화풍은 **맨 끝**으로 보냈다.
> 2. 부위별 묘사보다 **한국식 얼굴상**(여우상·두부상·고양이상 등)이 인상 전체를 더 잘 잡는다.
>    → 12명에게 서로 다른 얼굴상을 하나씩 줬다.
> 3. 따로 생성하면 모델은 다른 캐릭터를 모르니 **차이를 만들 이유가 없다**.
>    → **한 장에 여섯 명을 나란히 그려(라인업) 모델이 스스로 차이를 벌리게** 하고, 거기서 한 명씩 뽑는다.
> 4. 전원이 미소면 눈 모양이 같아진다. → **표정 12가지를 모두 다르게** 했다. 표정이 눈 모양을 바꾼다
>    (초승달로 감긴 눈, 반쯤 내리뜬 눈, 부릅뜬 눈, 흘겨보는 눈, 윙크, 찡그린 눈).

지난 판보다 **과감히 바꾼 설정**: 지우 머리(쇄골 C컬 → 낮게 묶은 쪽머리), 다은 머리(턱선 단발 → 턱선보다 짧은 일자 단발),
유나 눈(속쌍 → 무쌍)과 헤어 색(끝 옴브레), 도윤 얼굴(긴 각진형 → 넓고 두툼한 곰상), 건우 얼굴(둥근 사각 → 작고 동그란 수달상),
민재 모자 삭제(캡 그림자가 눈을 가려서), 서연 표정(한쪽 입꼬리 → 흘겨보는 정색). 성격·직업·옷·배경색은 그대로다.

**~상은 동물을 그리라는 뜻이 아니다.** 사람 얼굴의 인상을 가리키는 말이다. 모든 프롬프트에 "동물 귀·동물 특징 없음"을 넣었다.

## 3. 2단계 — 라인업에서 단독 프로필 뽑기 (캐릭터별)

**이 단계에서만 같은 대화를 쓴다.** 라인업 속 그 인물을 참조해야 하기 때문이다. 지난 판에서 "같은 대화 금지"라고 한
이유(앞 이미지의 얼굴이 복사됨)가 여기서는 원하는 효과가 된다. 다만 단독 프로필을 연달아 뽑다 보면 **앞 프로필의
얼굴이 다음 프로필로 번지기** 시작한다. 두 장이 닮아 보이면 그 대화를 버리고:

> **새 대화 → 저장해 둔 라인업 이미지만 첨부 → 아래 문장의 첫 줄을 "첨부한 라인업 이미지에서"로 바꿔 붙여 넣기.**
> (앞서 만든 단독 프로필은 첨부하지 않는다.)

모든 단독 프로필의 공통 규칙(각 블록에 이미 들어 있다): 1:1 정사각형 1024×1024, 인물 한 명, 얼굴은 가로 가운데,
머리 꼭대기~턱 끝이 세로 38~48%, 눈높이는 위에서 1/3, 원형으로 잘라도 머리카락·귀가 잘리지 않게 위·양옆 여백,
캐릭터 강조색 단색 배경. 화풍은 라인업 그대로.

## 4. 대안 — 개별 생성 프롬프트 (라인업이 잘 안 될 때)

라인업에서 한두 명이 끝내 안 나오면 그 사람만 **새 대화**에서 이 블록으로 뽑는다. 순서는 모델이 앞쪽을 더 세게
반영하는 점을 이용해 **얼굴상과 눈 → 코·입·얼굴형 → 표정 → 머리·색 → 옷·자세 → 구도·배경 → 화풍(맨 끝)** 이다.
블록 하나가 완결본이다(화풍 블록 §5가 이미 끝에 들어 있다).

라인업을 이미 만들었다면 새 대화에 **라인업 이미지를 첨부하고** 블록 맨 앞에 이 한 줄을 붙이면 화풍이 맞는다:
`첨부 이미지는 화풍 참고용입니다. 화풍·채색·선만 따르고, 인물의 얼굴은 첨부 이미지의 누구와도 다르게 아래 설명대로 그려 주세요.`

## 6. 얼굴이 또 비슷할 때 바로 쓰는 수정 문장

**원칙: 전부 다시 뽑지 말고, 한 사람의 한 부위만 고친다.** 끝에 항상 "나머지는 그대로"를 붙인다.
라인업에서는 "왼쪽에서 N번째 인물", 단독 프로필에서는 "이 인물"로 부른다. 괄호 안 값은 §1 표에서 가져온다.

### 6.1 눈만 같을 때

```
왼쪽에서 두 번째 인물의 눈을 쌍꺼풀 선이 전혀 없는 홑꺼풀로 바꾸고, 눈 크기를 지금의 절반 정도로 작고 가늘게 해 주세요. 나머지 인물과 이 인물의 다른 부분은 그대로.
```
```
왼쪽에서 첫 번째 인물의 쌍꺼풀 선을 지워 속쌍꺼풀로, 눈을 가로로 길고 가늘게 째지게, 눈꼬리를 날카롭게 치켜 올려 주세요. 나머지는 그대로.
```
```
왼쪽에서 네 번째 인물의 눈을 지금보다 훨씬 크고 동그랗게, 넓고 진한 겉쌍꺼풀로, 흰자가 많이 보이게 해 주세요. 나머지는 그대로.
```
```
왼쪽에서 여섯 번째 인물의 눈꼬리를 뚜렷하게 아래로 처지게 바꿔 주세요. 첫 번째 인물의 올라간 눈꼬리와 정반대가 되게. 나머지는 그대로.
```
```
여섯 명의 눈이 아직 비슷합니다. 무쌍 두 명(2번째, 6번째)은 쌍꺼풀 선을 완전히 지우고, 2번째는 가장 작은 눈, 4번째는 가장 큰 눈이 되게 크기 차이를 과장해 주세요. 나머지는 그대로.
```

```
여섯 명이 모두 비슷하게 웃고 있습니다. 표정을 이렇게 바꿔 주세요. 1번째: 웃지 않고 눈동자만 옆으로 흘겨보는 정색. 2번째: 졸린 듯 눈꺼풀이 반쯤 내려온 멍한 무표정. 3번째: 한쪽 눈썹만 치켜올린 반신반의. 4번째: 눈을 동그랗게 뜨고 입을 벌려 신나게 외침. 5번째: 입술을 삐죽 내민 서운한 얼굴. 6번째만 눈이 초승달로 감길 만큼 활짝 폭소. 얼굴 생김새와 머리·옷은 그대로.
```

```
(남성) 표정을 이렇게 바꿔 주세요. 1번째: 당황해 시선을 옆으로 피하고 입술을 앙다묾. 2번째: 한쪽 눈 윙크에 이를 다 드러낸 씩 웃음. 3번째: 웃음기 없는 무표정. 4번째: 고개 숙여 눈치 보듯 올려다봄. 5번째: 웃음을 참아 입꼬리가 말려 올라감. 6번째: 눈썹 안쪽이 올라간 걱정스러운 눈빛. 얼굴 생김새와 머리·옷은 그대로.

```


```
(남성) 왼쪽에서 두 번째 인물의 입을 훨씬 크고 입술을 두껍게, 여섯 번째 인물의 코를 크고 두툼하게 해 주세요. 세 번째 인물의 입술은 얇은 일자로. 나머지는 그대로.
```


## 7. 확인 체크리스트

라인업 단계에서:
- [ ] **머리와 옷을 손으로 가리고 눈·코·입만 봐도** 여섯 명이 구분되는가. (가장 중요. 안 되면 다음 단계로 가지 않는다.)
- [ ] 무쌍/쌍꺼풀이 §1 표대로인가. 특히 무쌍(다은·유나 / 하늘·승현)에 쌍꺼풀 선이 생기지 않았는가.
- [ ] 눈 크기가 적어도 세 단계로 보이는가(가장 작은 눈과 가장 큰 눈이 한눈에 차이 나는가).
- [ ] 표정 여섯 개가 서로 다른가. 웃는 사람이 두 명을 넘지 않는가.
- [ ] 얼굴상이 느껴지는가(여우상과 고양이상, 곰상과 공룡상이 서로 헷갈리지 않는가).
- [ ] **여성 여섯 명이 모두 예쁘고, 남성 여섯 명이 모두 잘생겨 보이는가.** 한 명만 처져 보이면 §6.10 마지막 문장.
- [ ] 매력의 종류가 서로 다른가(도도함·청초함·귀여움… §1.7). "다 같은 미인"이면 §6.10 세 번째 문장.

단독 프로필마다:
- [ ] 라인업의 그 인물과 같은 사람인가(눈 모양·쌍꺼풀·코·입·얼굴형).
- [ ] 앞서 뽑은 단독 프로필과 닮아 가지 않았는가.
- [ ] **모두 분명한 성인**으로 보이는가. 교복·앳된 느낌 없음.
- [ ] 선정성 없음. 트레이너 둘은 지퍼를 올린 여유 있는 상의, 몸이 아니라 얼굴과 표정이 중심.
- [ ] **실존 인물 닮음 없음**: 역이미지 검색(Google 렌즈, 네이버 스마트렌즈 등)으로 비슷한 실존 인물·연예인이 나오지 않는지.
- [ ] **글자·로고 없음**: 옷, 앞치마, 편지 봉투, 가운, 헤드셋에 흐릿한 가짜 글자까지 없는지.
- [ ] AI 오류: 손가락, 눈동자 좌우 방향, 귀걸이 짝, 안경테 끊김(정우), 헤드셋(소희)·청진기(승현), 이너컬러(소희), 땋은 머리·포니테일.
- [ ] 동물 귀·동물 특징 없음.
- [ ] 1:1, 배경이 캐릭터 색 단색이고 무늬·그림자 없음.
- [ ] 원형 크롭: 정사각형 가운데 원으로 잘라도 머리 꼭대기·귀가 잘리지 않음.
- [ ] 상업적 이용: 생성에 쓴 ChatGPT 요금제·시점의 이용 약관에서 생성물의 상업적 이용(앱 내 사용, 스토어 스크린샷)이 허용되는지 확인하고 날짜와 약관 링크를 기록.

12장 모아서:
- [ ] 12장을 나란히 놓고 머리·옷을 가린 채 얼굴만 보고도 12명이 구분되는가.
- [ ] 화풍·선 굵기·채도·밝기·얼굴 크기가 같은가.
- [ ] 같은 쪽 6명끼리 32pt 크기에서 헤어 실루엣과 색만으로 구별되는가.
- [ ] 라이트·다크 모드 둘 다에서 테두리와 그림이 어색하지 않은가.

**앱에서 어떻게 잘리나**: 앱은 정사각형을 **내접원**으로 자른다(가장 큰 곳 전화 화면 96pt, 캐스트 소개 카드 72pt,
가장 작은 곳 32pt). 32pt에서는 헤어 실루엣과 색이, 72pt 이상에서는 얼굴형·눈매·표정이 누구인지를 가른다.
가장자리에 강조색 1pt(전화 화면은 2pt) 테두리가 얹히므로 배경을 강조색 계열로 둔다.

## 8. 파일 규격과 앱에 넣는 법

| 항목 | 규격 |
|---|---|
| 경로 | `assets/portraits/<id>.jpg` (예: `assets/portraits/seoyeon.jpg`) |
| 파일 이름 | 캐릭터 id 그대로, **영문 소문자**. `seoyeon` `haneul` `jiwoo` `minjae` `yeeun` `doyun` `jeongwoo` `daeun` `seunghyun` `sohee` `geonwoo` `yuna` |
| 형식 | JPG 권장(용량). `.png`·`.jpeg`·`.webp`도 인식한다. 같은 id에 여러 형식을 두지 않는다 |
| 크기 | 정사각형 **768×768**(가장 큰 표시 96pt × 3배 = 288px의 2.5배 이상). 원본 1024×1024는 저장소 밖에 보관 |
| 용량 | 한 장 **200KB 이하** 권장(12장 합계 2.4MB 이하) |
| 하위 폴더 | 쓰지 않는다. `assets/portraits/draft/…` 는 무시된다 |

ChatGPT가 주는 PNG는 한 장 1~2MB라 줄여서 넣는다. 원본과 라인업 이미지는 저장소 밖(예: `~/Pictures/mossol_portraits/`)에 둔다.
macOS 기본 명령 `sips`만으로 된다.

```sh
# 원본 폴더에서 앱용 JPG 로 줄이기 (768px, 품질 80 → 보통 70~150KB)
cd ~/Pictures/mossol_portraits
for id in seoyeon haneul jiwoo minjae yeeun doyun jeongwoo daeun seunghyun sohee geonwoo yuna; do
  [ -f "$id.png" ] || continue
  sips -z 768 768 -s format jpeg -s formatOptions 80 "$id.png" \
    --out ~/workspace/mossol/assets/portraits/$id.jpg
done
ls -lh ~/workspace/mossol/assets/portraits

# 크기 확인
sips -g pixelWidth -g pixelHeight ~/workspace/mossol/assets/portraits/*.jpg
```

파일을 넣은 뒤:
- **코드·JSON 수정 없음.** `pubspec.yaml`에 `assets/portraits/` 폴더가 이미 등록돼 있고, 앱이 시작할 때
  `AssetManifest`를 읽어 `<id>` 그림이 있는 캐릭터만 그림으로 바꾼다. 없는 캐릭터는 이니셜 원 그대로다. 몇 장만 먼저 넣어도 된다.
- 새 파일은 번들에 들어가야 하므로 **앱을 완전히 다시 실행**한다(핫 리로드·핫 리스타트로는 안 보일 수 있다).
  `flutter run`을 끄고 다시 켜거나, 시뮬레이터용은 `flutter build ios --simulator --debug` 후 실행.
- `assets/portraits/.gitkeep`은 지우지 않는다(빈 폴더여도 빌드가 깨지지 않게 하는 파일).

### 8.1 넣은 뒤 앱에서 확인하는 순서
