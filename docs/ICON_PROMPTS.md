# 앱 아이콘 프롬프트 (ChatGPT 이미지 생성용)

모쏠 키우기 앱 아이콘을 ChatGPT 이미지 생성으로 만들 때 복사해 붙여 넣는 문서다.
완성본은 `assets/icon/app_icon.png`(1024×1024, 알파 없음)로 저장하고 §5대로 적용한다.
지금 들어 있는 `app_icon.png`는 임시본(그라데이션 배경 + 흰 말풍선 + 하트)이다.

## 지금 바로 하는 순서

1. §2 **방향 A** 프롬프트를 ChatGPT 새 대화에 붙여 넣는다(추천안, §3).
2. 결과를 §4 체크리스트와 §1의 "60px 테스트"로 본다. 틀린 부분은 §4의 수정 문장으로 고친다.
3. 마음에 들면 1024×1024 PNG로 저장해 `assets/icon/app_icon.png`를 교체한다.
4. 안드로이드용 전경 이미지(§5.2)를 같은 대화에서 하나 더 뽑는다.
5. §5대로 적용하고 시뮬레이터 홈 화면에서 확인한다(pubspec 수정은 리드가 한다).

---

## 1. 아이콘 전략 — 홈 화면 60px에서 읽히는 것

아이콘은 홈 화면에서 **약 60px**, 검색 결과에서 **약 40px**로 보인다. 1024px로 볼 때 예쁜 것과 작게 볼 때 읽히는 것은 다르다.

**읽히는 것**
- **굵은 실루엣 하나.** 한눈에 "말풍선", "하트", "글자 하나"로 말할 수 있어야 한다.
- **색은 1~2개 + 브랜드 핑크.** 브랜드 기준색 `#C2295A`(라즈베리 핑크, `AppPalette.rose600`)를 넓은 면으로 쓴다.
  보조색은 흰 계열 `#FFFAF9`(paper), 진한 톤 `#9E1B47`(rose700), 연한 톤 `#FFD9E2`(rose100) 안에서 고른다.
- **글자 없음.** 넣더라도 한글 **한 글자**까지(방향 C만).
- **평평한 단색 배경.** 그라데이션·질감·배경 소품 없음.

**안 읽히는 것 (피한다)**
- 가는 선, 작은 장식(반짝이, 점, 테두리 장식), 그림자 여러 겹.
- 전신이나 상반신, **작은 이목구비가 다 들어간 얼굴 전체**. 60px에서는 뭉개진 살색 덩어리가 된다.
- 여러 물체를 늘어놓은 장면(폰 + 하트 + 캘린더 + 캐릭터).

**규격**
- App Store 아이콘은 **1024×1024 PNG, 투명 없음(알파 없음), 모서리 둥글리지 않은 정사각형**. 모서리는 iOS가 알아서 깎는다.
  둥근 모서리를 직접 그리면 깎인 모서리 안에 또 모서리가 생긴다.
- **안전 여백 약 10%.** 핵심 형태는 가운데 약 80%(820px) 안에 둔다. 모서리가 깎여도 잘리지 않는다.

**피해야 할 것 (정책·반려)**
- **실존 브랜드 닮은꼴 금지.** 노란 배경에 갈색/검정 말풍선(국내 1위 메신저 느낌), 초록 말풍선(iOS 기본 메시지 느낌),
  파란 종이비행기 등. 말풍선은 **흰색 또는 핑크**, 배경은 **라즈베리 핑크**로 고정한다. 노란색·초록색은 쓰지 않는다.
- **미성년으로 보이는 캐릭터 금지.** 교복, 앳된 얼굴, 아기 같은 비율(방향 B). 캐릭터는 모두 성인(20대 중후반)이다.
- **선정적 요소 금지.** 입술 클로즈업, 키스, 노출, 윙크+혀 같은 암시.
- 하트 안의 숫자 배지("1", "99+")도 글자로 친다. 넣지 않는다.

**60px 테스트**: 결과 이미지를 화면에서 손톱만 하게 줄여 본다(맥 미리보기에서 축소, 또는 폰 사진첩에서 썸네일).
"무엇인지 1초 안에 말할 수 있는가", "주변 앱 아이콘과 구별되는가" 두 가지만 본다.

## 2. 세 가지 방향

모든 프롬프트는 **대상 → 구도·색 → 금지 → 화풍** 순서다. 화풍을 앞에 두면 모델이 화풍의 기본 그림을 먼저 떠올린다
(`docs/PORTRAIT_PROMPTS.md` §0과 같은 이유).

### 방향 A — 말풍선에서 돋아나는 하트 새싹 (추천)

**컨셉.** 메신저(말풍선) + 연애(하트) + **키우기(새싹)**. 톡 한 줄에서 마음이 자라는 게임이라는 걸 기호 하나로 말한다.
그냥 "말풍선 + 하트"는 연애·채팅 앱에 너무 흔해서 검색 결과에서 묻힌다. 하트를 **새싹의 떡잎 두 장**으로 만들면
"키우기"가 들어가 이 게임만의 아이콘이 된다. 성별 중립이라 남녀 캐릭터 양쪽 플레이어 모두에게 맞다.

```
앱 아이콘 하나. 가운데에 둥글고 통통한 흰색 말풍선 하나가 있고, 말풍선 꼬리는 왼쪽 아래를 향한다.
말풍선 안 가운데에서 작은 새싹 하나가 돋아나 있는데, 새싹의 떡잎 두 장이 합쳐져 하나의 하트 모양을 이룬다.
하트 떡잎은 진한 라즈베리 핑크(#C2295A보다 한 톤 진한 #9E1B47), 줄기는 짧고 굵다.
배경은 평평한 단색 라즈베리 핑크 #C2295A, 그라데이션·무늬·질감 없음. 말풍선은 따뜻한 흰색 #FFFAF9.
정사각형 1024×1024, 모서리를 둥글리지 말고 가장자리까지 배경색으로 꽉 채울 것.
말풍선과 새싹은 가운데 80% 안에 들어가고 사방에 약 10% 여백을 둘 것. 형태는 크고 단순하게, 선은 굵게.
텍스트, 글자, 숫자, 로고 넣지 말 것. 노란색·초록색 쓰지 말 것. 반짝이·작은 장식·그림자 여러 겹 없음.
화풍: 한국 로맨스 웹툰 앱의 아이콘처럼 깔끔한 디지털 일러스트. 부드러운 셀 채색, 말풍선 아래쪽에 연한 핑크 그림자 한 단계,
하트 떡잎 왼쪽 위에 작은 하이라이트 하나. 플랫에 가까운 부드러운 입체감.
```

**변형 (마지막 문단 앞에 한 줄 추가하거나 바꿔 넣기)**
- 새싹 대신: `말풍선 안에 하트 하나가 있고, 하트 아래쪽이 화분처럼 말풍선 바닥에 심겨 있다.`
- 볼 발그레: `말풍선 양쪽 아래에 옅은 분홍 볼터치 타원 두 개를 넣어 말풍선이 수줍어하는 얼굴처럼 보이게. 눈·입은 그리지 말 것.`
- 색 반전: `배경은 연한 핑크 #FFD9E2, 말풍선은 라즈베리 핑크 #C2295A, 하트 새싹은 흰색 #FFFAF9.`

**확인할 것**
- [ ] 60px에서 "말풍선 속 하트"가 1초 안에 보인다.
- [ ] 하트가 새싹(줄기 + 떡잎)으로 읽힌다. 그냥 하트로만 보이면 줄기를 굵게.
- [ ] 배경이 완전 단색이다(구석 색을 스포이트로 찍어 네 모서리가 같은지).
- [ ] 노란색·초록색이 없다. 초록 줄기가 나왔으면 핑크로 바꾼다(§4).
- [ ] 글자·숫자가 없다.

### 방향 B — 캐릭터 얼굴 크롭

**컨셉.** 스토어에서 **사람 얼굴은 가장 눈에 띈다.** 한국 로맨스 게임 이용자는 "누구랑 연애하는지"를 보고 설치한다.
12명 중 **건우(`geonwoo`)**를 고른다.
- 배경색 더스티 로즈 `#FFDFE5`가 브랜드 핑크와 바로 이어진다(다른 캐릭터는 보라·청록·민트 등).
- 대표 표정이 **웃음**(보조개 + 입꼬리)이라 작게 줄여도 "웃는 얼굴"로 읽힌다. 서연(흘겨봄)·승현(무표정)·다은(멍함)은
  작게 보면 화난 얼굴이나 무표정으로 읽힌다.
- 볼륨 펌 갈색 머리가 동그란 실루엣을 만든다. 긴 생머리(서연)나 버즈컷(도윤)보다 크롭했을 때 윤곽이 또렷하다.
- 이 장르 핵심 이용자층(20대 여성)에게 가장 무난한 "귀엽고 다정한 훈남"이다.

**약점.** 남성 캐릭터 하나만 보이면 여성 캐릭터를 찾는 남성 플레이어가 "여성향 전용"으로 오해한다. 캐스트가 반반인 게임에서
한쪽만 대표하게 된다. 초상화 화풍(가는 선, 섬세한 머릿결)은 60px에서 디테일이 뭉개지므로 **얼굴을 크게 잘라야** 한다.

ChatGPT에 `assets/portraits/geonwoo.jpg`를 **첨부**하고 붙여 넣는다.

```
첨부한 캐릭터와 같은 사람으로, 앱 아이콘 하나를 그려 줘.
얼굴을 아주 크게: 이마 위 머리 볼륨부터 턱 바로 아래까지만 보이게 잘라서 얼굴이 화면 가운데 80%를 채우게 한다.
볼륨 있는 갈색 가르마펌, 큰 쌍꺼풀 눈, 양 볼의 깊은 보조개, 입꼬리가 말려 올라간 웃음, 왼쪽 덧니가 살짝.
첨부한 사람의 얼굴상과 이목구비를 그대로 유지할 것. 지금의 성인(20대 중반) 모습. 앳되게 만들지 말 것.
얼굴 오른쪽 위에 작은 흰색 하트 말풍선 하나(윤곽이 굵고 단순하게).
배경은 평평한 단색 라즈베리 핑크 #C2295A, 그라데이션·무늬 없음.
정사각형 1024×1024, 모서리를 둥글리지 말 것, 사방 약 10% 여백 안에 얼굴의 핵심(눈·입)이 들어갈 것.
텍스트, 글자, 숫자, 로고 넣지 말 것. 손·어깨·옷은 거의 보이지 않게.
화풍: 한국 로맨스 웹툰풍 반실사 디지털 일러스트, 부드러운 셀 채색. 아이콘용이라 외곽선은 평소보다 굵게, 머릿결 잔선은 줄이고 큰 덩어리로.
```

**변형**
- 여성 대안: `assets/portraits/sohee.jpg` 첨부, 설명을 `눈썹 위 일자 뱅, 밀크 브라운 울프컷에 안쪽 청록 이너컬러, 아주 큰 동그란 눈, 발그레한 볼, 신나게 웃는 입`으로.
  소희는 배경색(하늘색)이 브랜드와 멀어 핑크 배경 위에서 머리색 대비가 약하다. 이너컬러 청록을 조금 더 진하게 요청한다.
- 두 사람: 얼굴 두 개(건우 + 소희)를 좌우로 반씩 잘라 맞대기. 60px에서 거의 확실히 뭉개지므로 **비추천**.
- 배경 톤다운: `배경은 연한 핑크 #FFD9E2, 하트 말풍선은 라즈베리 핑크 #C2295A.`

**확인할 것**
- [ ] 첨부한 초상화와 같은 사람으로 보인다(보조개·덧니·펌).
- [ ] 20대 중반으로 보인다. 어려 보이면 §4 "어려 보임" 문장.
- [ ] 60px에서 눈과 웃는 입이 구별된다. 안 되면 더 크게 크롭.
- [ ] 입술·목선 클로즈업 등 선정적으로 읽히는 구도가 아니다.

### 방향 C — 한글 한 글자 로고 마크 "쏠"

**컨셉.** 게임 이름의 핵심인 **"쏠"** 한 글자를 굵은 로고로. 한국어 사용자는 글자를 그림보다 빨리 읽는다.
"ㄹ" 받침의 마지막 획 끝을 작은 하트로 맺어 연애 게임임을 알린다. 차별성은 가장 크지만 감정 전달(설렘)은 A·B보다 약하고,
ChatGPT가 한글을 틀리게 쓰는 경우가 있어 **글자 모양을 반드시 확인**해야 한다. 틀리면 글자는 폰트로 직접 얹고
ChatGPT에는 배경 + 하트만 그리게 하는 편이 빠르다(아래 변형 3).

```
앱 아이콘 하나. 가운데에 한글 한 글자 "쏠"을 아주 굵고 둥근 고딕 글씨로 크게 쓴다.
글자는 정확히 "쏠" (쌍시옷 ㅆ + 모음 ㅗ + 받침 ㄹ). 다른 글자, 영어, 숫자는 넣지 말 것.
받침 ㄹ의 마지막 획 끝이 작은 하트 모양으로 맺힌다. 획 끝은 둥글게.
글자색은 따뜻한 흰색 #FFFAF9, 하트는 연한 핑크 #FFD9E2.
배경은 평평한 단색 라즈베리 핑크 #C2295A, 그라데이션·무늬·질감 없음.
정사각형 1024×1024, 모서리를 둥글리지 말 것. 글자는 가운데 약 70% 안에 들어가고 사방 여백을 넉넉히.
글자 외 장식·반짝이·그림자 여러 겹 없음.
화풍: 한국 로맨스 웹툰 타이틀 로고처럼 깔끔한 벡터풍 디지털 일러스트. 글자 아래쪽에 한 단계 진한 핑크 #9E1B47 그림자를 살짝 두어 도톰해 보이게.
```

**변형**
- 두 글자: `"쏠"` 대신 `"모쏠"`, 두 글자를 위아래가 아니라 좌우로 붙이고 글자 전체가 가운데 80% 안에.
  60px에서 두 글자는 한 글자보다 덜 읽힌다.
- 말풍선 결합: `글자 "쏠"을 흰 말풍선 안에 라즈베리 핑크 #C2295A 글씨로 넣는다. 말풍선 꼬리는 왼쪽 아래.` (A와 C의 결합)
- 글자 없이 받기: `글자를 넣지 말고, 가운데에 흰색으로 둥근 네모 영역만 비워 두고 오른쪽 아래에 작은 하트만 그려 줘.` → 글자는
  Pretendard ExtraBold로 직접 얹는다(앱 번들 폰트, 라이선스 OK).

**확인할 것**
- [ ] 글자가 정확히 "쏠"이다(ㅆ 두 개, ㅗ, ㄹ). "쑬", "솔", "쏼"이면 다시.
- [ ] 하트가 획에 붙어 있고 따로 떠 있지 않다.
- [ ] 60px에서 글자가 읽힌다.
- [ ] 글자 외 텍스트가 없다.

## 3. 추천: 방향 A

1. **양쪽 캐스트를 다 대표한다.** 이 게임은 성별을 골라 남녀 캐릭터 각 6명을 만난다. 얼굴 하나(B)는 절반의 플레이어에게
   "내 게임이 아니다"라는 신호가 된다. 말풍선 + 하트는 20대 여성·남성 모두에게 "연애 톡 게임"으로 읽힌다.
2. **60px에서 가장 확실하다.** 굵은 도형 두 개(말풍선, 하트)라 검색 결과 40px에서도 깨지지 않는다. B는 반실사 초상화 디테일이
   작게 줄면 뭉개지고, C는 한글 렌더링 오류 위험이 있다.
3. **포지셔닝과 바로 맞는다.** "메신저로 썸부터 고백까지"가 말풍선 하나로 설명되고, 새싹 하트가 "키우기"와 100일 성장을 더한다.
   흔한 "말풍선 + 하트"와도 구별된다.
4. **화풍 일관성.** 셀 채색 + 부드러운 하이라이트로 그리면 캐릭터 일러스트와 같은 톤이 된다. 얼굴은 스크린샷(캐스트 소개 화면)이
   맡는다 — 아이콘은 "무슨 게임", 스크린샷은 "누구와"를 담당하게 나눈다.

B는 스토어 첫인상은 강하므로, 출시 뒤 전환율이 낮으면 A/B 테스트(App Store Connect "제품 페이지 최적화", 대체 아이콘 필요)로
B를 시험해 볼 수 있다. C는 브랜드 인지도가 생긴 뒤에 유리하다.

## 5. 앱에 적용하기

### 5.1 파일 준비

- iOS·스토어용: **1024×1024 PNG, 알파 없음** → `assets/icon/app_icon.png` (기존 파일 교체).
  ChatGPT 이미지가 1024가 아니면 맥에서 `sips -z 1024 1024 파일.png --out assets/icon/app_icon.png`.
  알파 확인: `sips -g hasAlpha assets/icon/app_icon.png` → `hasAlpha: no` 이어야 한다
  (`remove_alpha_ios: true`가 처리하지만 스토어 업로드용 원본도 알파가 없어야 한다).

### 5.2 안드로이드 적응형 아이콘 전경 (선택, iOS 우선이면 나중에)

안드로이드는 원·물방울 등 기기마다 다른 모양으로 자르므로 **배경색과 전경 그림을 따로** 준다.
같은 대화에서:

```
방금 아이콘에서 배경을 완전히 투명하게 하고 가운데 그림(말풍선과 하트 새싹)만 남긴 PNG를 만들어 줘.
정사각형 1024×1024, 그림은 가운데 약 60% 안에만 들어가게 작게 줄이고 나머지는 투명.
```

→ `assets/icon/app_icon_foreground.png` 로 저장. 이때는 **알파가 있어야 한다**(`hasAlpha: yes`).

### 5.3 pubspec 설정 (리드가 적용)

이 문서 작성자는 `pubspec.yaml`을 고치지 않는다. 리드가 아래를 넣는다.

```yaml
dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^6.0.0
  flutter_launcher_icons: ^0.14.4

flutter_launcher_icons:
  image_path: "assets/icon/app_icon.png"
  ios: true
  remove_alpha_ios: true
  android: true
  min_sdk_android: 21
  adaptive_icon_background: "#C2295A"
  adaptive_icon_foreground: "assets/icon/app_icon_foreground.png"
```

- 전경 PNG가 아직 없으면 `adaptive_icon_background` / `adaptive_icon_foreground` 두 줄을 빼면 된다
  (안드로이드는 `image_path`로 기존 방식 아이콘만 만든다).
- 방향 A의 배경색이 `#C2295A`가 아니게 나왔으면 `adaptive_icon_background`를 실제 배경색(스포이트 값)으로 맞춘다.

### 5.4 생성 명령

```bash
cd /Users/hyukahn/workspace/mossol
flutter pub get
dart run flutter_launcher_icons
```

`ios/Runner/Assets.xcassets/AppIcon.appiconset/`의 `Icon-App-*.png`와 `android/app/src/main/res/mipmap-*`가 새로 생긴다.
`Icon-App-1024x1024@1x.png`를 열어 새 그림인지 확인한다.

### 5.5 시뮬레이터 홈 화면에서 확인

iOS는 홈 화면 아이콘을 캐시하므로 **앱을 지우고 다시 설치**해야 바뀐다.

```bash
xcrun simctl uninstall booted com.hyukahn.mossol
flutter run   # 또는 Xcode에서 Run
```

1. 시뮬레이터에서 홈으로 나간다(⇧⌘H).
2. 아이콘이 모서리가 깎인 상태로 잘리지 않는지, 이름 "모쏠 키우기"가 아래에 나오는지 본다.
3. 다크 모드(설정 → 디스플레이)와 라이트 모드 배경화면 양쪽에서 구별되는지 본다.
4. 스포트라이트 검색(홈에서 아래로 쓸기)에서 작은 크기로 한 번 더 본다 — §1의 60px/40px 테스트.
5. 여전히 옛 아이콘이면 시뮬레이터 → Device → Restart 후 다시 본다.
