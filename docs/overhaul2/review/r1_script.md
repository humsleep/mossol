## 표기

- 위치: `L3` = `lines[3]`, `C2` = `choices[2]`(선택지 문구), `C2.reply[1]` = 그 선택지의 `reply[1]`. `cliff` = `cliffhanger`. 인덱스는 0부터.
- 등급: **P0** 깨짐·모순·준수 문제 / **P1** 확실히 약함·캐릭터 이탈 / **P2** 다듬기.
- 표 안의 `\|` 는 템플릿의 `|` 다(마크다운 표 이스케이프). JSON 에 옮길 때 `\` 를 빼고 `|` 로 쓴다.
- 돈 단위: 게임 돈 1 = 천 원. 화면 표기는 `Money` 규칙대로 `7.2만원`·`5천원`(붙여 쓴다). 대사 속 금액은 효과값과 같아야 한다.
- 디데이 기준: `m_week1` 의 "D7 = D-93" 을 정본으로 본다(Dn = D-(100−n)). 그러면 D2 = D-98, D3 = D-97.

## 구조적으로 먼저 볼 것 (표의 행 여러 개에 걸친 문제)

1. **인트로와 D1 의 시점이 엇갈린다.** `starts.json` 의 `introLine` 이 전부 "어제 ~했어"(이미 일어난 일)인데, D1 메인은 같은 사건을
   지금 일어나는 일로 보여 주고, 태현도 D1 에 처음 듣는 것처럼 반응한다(`sc_leak_d1a` "너 지금 그걸 알바 단톡에?", `sc_clip_d1` "야 이거 너지??",
   `sc_ghost_d2` "야 할 말 있는데"). 인트로를 **사건 직전·직후의 실시간 톡**으로 바꾸는 안을 아래 표에 적었다.
2. **D1·D2·D3 의 일상·분기 이벤트 클리프행어는 화면에 나오지 않는다.** `_noteCliffhanger` 는 층 순위(main > … > daily)로 하루 한 줄만
   남긴다. 신규 시작은 D1~3 에 항상 메인이 있으므로 `_d1a/b/c`(15개), `_open_1/2`, `d_brief_alt` 의 클리프행어는 죽은 글이다.
   그런데 `sc_leak_d2`(단톡 이름 '수사본부')와 `sc_leak_d1c.C2.reply[1]`("단톡 이름은 **그대로**")은 그 죽은 클리프행어를 전제로 한다.
3. **신규 시작의 사건이 r00 첫 접촉보다 먼저 일어나는데, r00 은 그걸 모른다.** 다은·하늘(sc_leak), 소희·민재(sc_clip),
   예은·건우(sc_speech), 서연·정우(sc_swap), 승현(sc_ghost), 유나·도윤(sc_swap C 갈래)의 첫 접촉 대사가 "처음 연락"으로 쓰여 있다.
   r00 은 D1~100 에 호감 15 이하일 때만 나오고 신규 시작은 짝에게 호감 +4 를 주므로, r00 이 **사건 뒤에** 나올 확률이 높다.
   r00 에 시작 플래그 파급 줄을 더하는 안을 적었다(루트 파일 수정은 이 리뷰의 범위 밖이라 제안만 한다).
4. **대사 속 금액과 돈 효과가 10배 어긋나는 곳이 9군데다.** `money: 12` 인데 "12만 원"처럼 쓴 경우다. 대사를 효과에 맞춘 안을 적었다.
