**교체안 (엔진 담당).** 4차 규칙의 장점(새벽은 하루 맨 앞)과 4차 이후 규칙의 의도(메인 고정 순서)를 함께 살린다.
```
orderByClock(plan):
  dawn    = 메인이 아니고 clock < 06:00          → 시각 순, 하루 맨 앞
  mains   = 메인 중 clock 이 없거나 < 12:00     → 원래 순서
  morning = 메인이 아니고 06:00 ≤ clock < 12:00 → 시각 순, 메인 바로 뒤
  rest    = clock 없음                            → 원래 순서
  late    = clock ≥ 12:00 (메인 포함)             → 시각 순, 하루 맨 뒤
  return dawn + mains + morning + rest + late
```
