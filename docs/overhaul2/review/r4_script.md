## 표기

1~3차와 같다. `L3` = `lines[3]`, `C2` = `choices[2]`, `C2.reply[1]`. 인덱스는 0부터 센다(현재 파일 기준).
등급
- **P0**: 깨짐·모순. 거의 모든 회차에 보인다.
- **P1**: 확실히 약함, 갈래 한정 모순, 캐릭터 이탈.
- **P2**: 다듬기.

교체안은 그대로 JSON 에 붙여 넣을 수 있게 썼다. "추가"는 바로 앞에 적은 줄 뒤에 넣는다는 뜻이다.
교체안은 엔진 수정 없이 들어간다. 엔진 담당의 확인이 필요한 곳은 따로 적었다.

### R4-2 · P1 · sc_ghost_settle_open 보류 갈래의 L2
